## 实现方案：BBox AI 分析 + 新 JSON schema + 设置 agent 配置

### 决策汇总
- **示例 JSON 改用新 schema**：`{title, elements[]}`，元素含 `coords:[x,y,w,h]`/`type`/`parentId`/`exportSlice`/`ocrText`/`textRole`/`children`
- **解析逻辑兼容新旧两种 schema**：新（`elements`+`coords`+`children`）+ 旧（`ui_elements`+`bbox_2d`+`children`）
- **设置加「BBox AI 分析」配置区**：agent preset（openAgentEditor）+ 可编辑系统提示词（默认填用户给的检测提示词）
- **BBox 查看器加「AI 分析图片」按钮**：把当前图 URL + 提示词 → `agent_run` → 解析返回 JSON → 自动渲染框
- **图片传给 AI 的方式**：prompt 里嵌入图片 http URL（agent runtime 自带读图工具），零宿主改动

### 新 schema 解析逻辑（关键技术点）
```
新 schema: { title, elements: [{id, type, label, coords:[x,y,w,h], parentId, exportSlice, ocrText?, textRole?, children?[]}] }
旧 schema: { ui_elements: [{id, label, bbox_2d:[x1,y1,x2,y2], children?[]}] }
```
- `coords [x,y,w,h]` → box `{x, y, width, height}`（直接用）
- `bbox_2d [x1,y1,x2,y2]` → box `{x:x1, y:y1, width:x2-x1, height:y2-y1}`（旧逻辑）
- 递归 children 两种 schema 都支持
- 元数据扩展：`meta = {id, label, depth, color, type, exportSlice, ocrText, textRole}`，图例可展示 type/ocrText
- `exportSlice=true` 的框用不同视觉（如填充半透明绿）区分「可导出资产」vs「容器面板」

### 坐标系换算（保留）
新 schema 的 coords 是像素值（按提示词），但若所有值 ≤1000 且图 >1000px 仍按 1000 坐标系换算（兼容 LLM 归一化输出）。

### AI 返回 JSON 提取（鲁棒性）
```js
function extractJson(text) {
  // 1. 优先匹配 ```json ... ``` 代码块
  const m = text.match(/```(?:json)?\s*([\s\S]*?)```/);
  if (m) return JSON.parse(m[1]);
  // 2. 兜底找第一个 { 到最后一个 }（LLM 可能前后带解释）
  const s = text.indexOf('{'); const e = text.lastIndexOf('}');
  if (s >= 0 && e > s) return JSON.parse(text.slice(s, e + 1));
  throw new Error('AI 未返回有效 JSON');
}
```

### 验收要点
- 设置对话框出现「BBox AI 分析」分区，可配置 agent + 编辑系统/用户提示词
- BBox 查看器顶栏出现「✨ AI 分析」按钮
- 点「载入示例」→ 新 schema 的框渲染（含 type/ocrText 展示）
- 点「✨ AI 分析」→ 用配置的 agent 分析当前图 → 返回 JSON 自动渲染成框
- 未配置 agent 时点 AI 分析提示去设置
- 旧格式 JSON（ui_elements+bbox_2d）仍能正常导入（向后兼容）

### 不做的事
- 不改宿主层（agent_run/openAgentEditor/callPluginTool 已暴露）
- 不把图片 base64 塞进 prompt（URL 方式更轻，agent runtime 自带读图）
- 不做 AI 流式输出（agent_run 是一次性返回 result）
