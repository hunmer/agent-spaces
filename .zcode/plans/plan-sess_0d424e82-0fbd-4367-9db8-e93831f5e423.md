## 新增「执行工作流」节点方案

### 设计要点
- **工作流选择**：复用 SettingsDialog.jsx 已验证的模式——节点内放「选择工作流」按钮（`WorkflowSlot` 样式），点击通过 `callPluginTool('@agent-spaces/builtin','list_workflows')` 拉数据，弹已暴露的 `WorkflowListDialog`，选中回填 `{workflowId, workflowName}` 到 `data.params`。
- **JSON 参数编辑**：把 `MonacoCodeEditor`（`packages/web/src/components/editor/monaco-code-editor.tsx`，独立薄封装）新增导出到 `@agent-spaces/ui`。节点内 `language="json"` 渲染，`onChange` 实时解析存到 `data.params.input`（对象）。
- **执行**：节点内直接调 `runWorkflow(workflowId, input, { returnRawEndOutput: true })`（已存在工具），拿到 end 节点完整 output。**不**走 `onGenerate`（通用节点工作流 ID 在节点上选，不走 settings 槽位；状态自管）。
- **URL 提取**（智能 + 可配）：
  - 用户在节点上填「URL 字段路径」（可选，如 `result` / `data.images` / `output.url`）。
  - 填了 → 按点分路径从 output 取值，支持数组展开。
  - 没填 → 智能提取（复用 `extractOutput` 思路：end 节点 `result/images/image_urls` + 任意 completed 节点 `data.images`），并在 steps 里递归扫描所有 http/data URL 字符串兜底。
- **Gallery**：提取出的 URL 写入 `data.output.images`，复用现有 `NodeOutput` + `ImageResult`（点击用 `openMediaGallery` 看大图，含版本/清空/加图等）。
- **中断**：执行开始时 `subscribeWorkflowEvents` 订阅 `workflow:started` 回填 `executionId` 到节点 data；取消按钮调 `stopWorkflow(executionId)` + `AbortController` 中断 fetch。

- #2 NodeResizer：initialData 配 `DEFAULT_SIZE` + NodeShell 带顶层 width/height/style。
- #3 交互抑制：MonacoCodeEditor 外层 div + WorkflowListDialog 内容加 `nodrag nopan nowheel`。
- #12 图标从 `@agent-spaces/ui` 命名导入。

- 上传/连线：本节点无图片输入（纯 JSON），不涉及 #4。

### 不做的事
- 不改 `react-renderer.tsx`（`...AgentSpacesUI` 自动展开新导出）。
- 不动 settings.js（通用节点无 settings 槽位）。
- 不实现 agent 自动执行（留给后续，需先定义 agent 如何知道目标工作流的 input schema）。
