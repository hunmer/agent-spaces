# 节点预设库实现计划

## 存储方案（关键决策）
采用**全局共享**：预设存顶层 `node-presets.json`，走项目标准的「三重读取」(`getConfig` + `onConfigReady` + `onAnyConfigChanged`) + `writeConfigJson` 单写者模式（与 usePanelLayout 一致）。预设是模板，跨工作区复用。

## 预设数据结构
```js
{
  id: 'preset-xxxx',          // genId('preset')
  name: '预设名',
  createdAt: 1234567890,
  // 坐标归一化：所有节点 position 减去左上角基准点，还原时按落点偏移
  nodes: [{ id, type, position, width, height, style, data }],
  edges: [{ source, target, sourceHandle, targetHandle, data }], // 仅选中集合内的内部连线
  groups: [{ name, childNodeIds, childGroupIds }],  // id 用预设内节点的原始 id 引用
}
```
- 保存时复用 `clipboard.js` 的 `INJECTED_DATA_KEYS`/`TRANSIENT_DATA_KEYS` 思路剥离函数回调和瞬时数据（output/images/status/loading 等），保证预设纯净。
- 坐标归一化：`minX/minY` 置零，还原时整体平移。

## 新增文件（4 个）

### 1. `src/hooks/useNodePresets.js`
CRUD hook，参考 `usePanelLayout.js` 三重读取范式：
- 返回 `{ presets, addPreset, removePreset, renamePreset }`
- `PRESETS_CONFIG = 'node-presets.json'`（加到 `constants.js`）
- `addPreset({ name, nodes, edges, groups })` → 序列化选中集合并持久化

### 2. `src/utils/node-preset.js`
纯函数工具，无副作用：
- `serializePreset(selectedNodes, allEdges, groups, name)` → 干净预设对象（剥离瞬时数据 + 坐标归一化）
- `instantiatePreset(preset, { genId, offset })` → `{ nodes, edges, groups }` 重建（新 id 映射 + 内部连线重连 + 组重建）
- 还原逻辑参考 `clipboard.js` 的 `pasteNodes`：生成 idMap，重连 edges，重建 groups。

### 3. `src/components/right-panel/PresetsTab.jsx`
参考 `AddNodeTab.jsx` 的卡片网格 + DnD 模式：
- 顶部：标题 + 预设计数
- ScrollArea 内：卡片网格（响应式列数，复用 `MIN_CARD_WIDTH/MIN_COLS`）
- 每张卡片：拖拽手柄（主体）+ 左上角「+」添加到视口中心 + 右上角删除（hover 显示）
- 拖拽：`onDragStart` 写入 MIME `application/x-node-preset`（payload = 预设 id）
- 空态：引导文字「在底部工具栏选中多个节点后点【保存预设】」

### 4. `src/components/SavePresetDialog.jsx`
新建预设对话框，参考 `GroupConfirmDialog.jsx`：
- 输入框：预设名称
- 列表区：展示待保存的节点（图标 + label，用 `NODE_META`）和涉及的分组数
- 确定/取消

## 拖拽协议
新增 MIME：`application/x-node-preset`（payload = 预设 id 字符串）。
- 与现有协议不冲突：`CANVAS_DROP_MIME`（图片）、`application/x-history-patch`（历史项）、`application/reactflow`（单节点类型）。
- `handleDrop` 优先级：files > history-patch > canvas-drop-images > **node-preset（新）** > reactflow 单节点。

## 成功标准
- 多选节点/组 → 底部工具栏点【保存预设】→ 弹对话框（标题+节点列表）→ 确认后预设 tab 出现新卡片
- 预设卡片「+」点击 → 在视口中心还原节点+连线+分组
- 预设卡片拖到画布 → 在落点还原（避让已有节点）
- 刷新页面预设仍在（持久化生效）
