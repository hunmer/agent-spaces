# 新增「动画帧编辑器」节点

## 目标
在 game-asset-canvas 新增节点 `frameEditor`：接收上游多图或本地上传图片，节点内展示「编辑」按钮，点击弹出对话框，用 scenejs-timeline(CDN esm.sh ESM) 展示时间线 + 可拖拽预览区，支持调整序列帧的**时间线出现时机**与**画面 x/y 偏移**，播放器控制序列帧显示，最终可导出 GIF。

## 决策（已与用户确认）
- **位置语义**：两者都要 —— 时间线拖动调出现时机（setDelay，scenejs 原生）+ 预览区拖动调 x/y 偏移（自实现，存帧元数据）
- **CDN**：esm.sh ESM，经宿主已有 `window.AgentSpaces.loadCdnModule` 加载（零宿主改动，刷新即生效）
- **GIF 导出**：复用项目已有 `utils/image-ops/gif.js` 的 `encodeFramesToGif`（gifenc，已 CDN 化）

### 1. `src/utils/constants.js`（改）

- `IMAGE_TAGS` 加 `frameEditor: '帧编辑'`

### 2. `src/components/nodes/FrameEditorNode.jsx`（新增）
仿 `ImageEditorNode`：
- 多图输入：`FileUpload`（maxFiles=0 不限）+ 上游连线多图只读占位区
- 合并去重 `dedupeUrls([...uploadedImages, ...upstream])` 得到输入帧
- 统计行「输入 N 帧（上传 X + 连线 Y）」
- 「🎞️ 编辑帧序列」按钮 → 打开 `FrameEditorDialog`
- 对话框关闭后产出写入 `data.output.images`（导出的 GIF URL）
- 产出展示 `ImageResult`

### 3. `src/components/FrameEditorDialog.jsx`（新增）
核心编辑器对话框（`Dialog` from `@agent-spaces/ui`，大尺寸 `!w-[90vw] max-w-[90vw]`）。
结构：
- **顶部工具条**：帧间隔(ms) 输入、画布尺寸(宽/高，默认取首帧自然尺寸)、「导出 GIF」「关闭」
- **左侧预览区**（flex-1，相对定位深色背景）：
  - 监听 scene 的 animate，按当前 time 选出应显示的帧渲染 `<img>`
  - 该 `<img>` 可鼠标拖拽（mousedown/move/up 记录 dx/dy），更新该帧的 `offsetX/offsetY`（存入帧元数据 Map）
  - 显示当前帧序号/时间/偏移量
- **底部 scenejs-timeline 容器**（固定高 ~260px，ref div）：
  - 懒加载 Scene + Timeline，`new Timeline(scene, containerRef.current, {keyboard:true, onSelect})`
  - 每个序列帧建一个 SceneItem：`scene.newItem('frame'+i, {selector:false})` + `item.set({0:{opacity:0}, [t]:{opacity:1}})` 表达"t 时刻该帧可见"，`item.setDuration(frameDuration)`
  - 用户在时间线拖动整段色块（keyframe-group）→ scenejs 自动 `item.setDelay()`，重排出现时机
  - 播放控制走 scenejs 自带 ControlArea（Space 播放/暂停、左右微调）

**帧元数据**：`framesMeta = [{ url, delay, duration, offsetX, offsetY }]`，作为单一数据源。打开对话框时按输入帧初始化（每帧 duration 默认 = 帧间隔 ms 转 s，offsetX/Y=0，delay = i*duration）。

**导出 GIF 流程**：
1. 取 `framesMeta` 按 delay 升序排序（时间线重排后的顺序）
2. 逐帧 `urlToImageData(url)`（跨域经 `proxyImageUrl` 代理）
3. 每帧按画布尺寸绘制到合成 canvas（先清透明，再 drawImage 到 `offsetX, offsetY`）→ 得到等尺寸 ImageData
4. 复用 `encodeFramesToGif(imageDataList, frameIntervalMs)` → Blob
5. `uploadFile(blob)` → http URL → `onSave([gifUrl])`

### 4. `src/utils/image-ops/cdn.js`（改）
新增 `getSceneTimeline()` 加载器（与现有 `loadVendor`/`loadCdnModule` 不同，走宿主 `loadCdnModule`）：
```js
export async function getSceneTimeline() {
  const AS = window.AgentSpaces;
  const Scene = await AS.loadCdnModule('https://esm.sh/scenejs@1.9.6');
  const Timeline = await AS.loadCdnModule('https://esm.sh/@scenejs/timeline@0.3.0');
  return { Scene: Scene.default || Scene, Timeline: Timeline.default || Timeline };
}
```

## 关键技术点
- scenejs-timeline 是"属性动画时间线"，序列帧可见性用 `item.set({opacity:[0→1]})` 表达；拖 keyframe-group → `item.setDelay()` 是原生能力，无需自实现
- Timeline 渲染会把 UI DOM 挂到传入的 container，卸载时需 `container.innerHTML=''` 清理
- Scene 配置 `selector:false` 避免它去查 DOM 选择器；播放/暂停用 `scene.play()/pause()`，时间由 `scene.on("animate", e=>e.time)` 取
- 跨域图片：上游 URL 可能跨域，`urlToImageData` 前先 `window.AgentSpaces.proxyImageUrl(url)` 代理
- GIF 编码要求各帧 ImageData 尺寸一致 → 合成 canvas 统一到「画布尺寸」（默认首帧自然尺寸，可手填）

## 不做
- 不改宿主层（react-renderer/ui-exports/use-mini-app-host-api）—— loadCdnModule 已存在，零宿主改动
- 不加 npm 依赖 —— scenejs/timeline 走 CDN，gifenc 已在项目 vendor
- 不做帧重排的拖拽动画细节优化（首次能用即可，符合「先完成不追求完美」）

## 验收步骤
1. 重启后打开 game-asset-canvas，右侧「新增节点」可见「🎞️ 动画帧编辑器」
2. 拖入画布 → 上传 ≥2 张图（或连线上游多图节点）→ 点「🎞️ 编辑帧序列」
3. 弹出对话框：底部出现 scenejs 时间线，每帧一段色块；Space 播放可见预览区按时间切换帧
4. 拖动时间线某段色块 → 该帧出现时机改变；在预览区拖动当前帧 → x/y 偏移生效（帧移到偏移位置）
5. 点「导出 GIF」→ 等待生成 → 节点产出区显示 GIF，下游可连线，NodeToolbar 导出按钮可用
6. 断网时编辑器加载报错但不崩溃（状态标 error）
