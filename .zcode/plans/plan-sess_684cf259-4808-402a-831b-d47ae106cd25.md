## 「不检测」功能改动（3 处）

1. **`SplitterToolbar.jsx` full 模式下拉框**：在检测方法 `<select>` 增加 `<option value="none">不检测</option>`（置于首项，与 grid-only「不处理」顺序一致）。新顺序：不检测 / 四角背景色 / 吸取背景色 / Alpha 非透明 / 暗色前景。

2. **主文件 `detectAll`**：函数顶部加 `if (methodRef.current === 'none') return 0;` —— 切到 none 时不触发检测、不清空画布、不动现有切片框。（auto-detect effect 472-475 调 detectAll，间接受益，无需改 effect）

3. **主文件初始加载检测循环**(~724 行 else 分支)：增加 `else if (opts0.method === 'none') { s0.rects = []; }` —— none 模式且无持久化切片时留空，等用户手动框，不跑 `detect()`。

导出侧无需改：`exportBox`(sprite-splitter.js:109) 在 `method==='none'` 时 `transparent=false`，自动保留原像素不抠背景，符合「导出按原图裁剪」。
持久化侧无需改：`syncSplitData` 写 `method:'none'` 字符串，恢复路径已通用。
