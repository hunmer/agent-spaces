# 重构计划：按功能拆分 `packages/server/src/services/team.ts`

## 目标
将 1587 行的单体 `team.ts` 按功能拆分为多个文件，**保持对外 10 个导出符号与所有 import 路径完全不变**（零破坏）。

## 拆分策略：平铺 + 前缀 + barrel（与 `execution-*` / `mini-app-*` 惯例一致）

保持 `team.ts` 作为入口 barrel（re-export），所有外部消费者（`routes/team.ts`、`team-tools.ts`、`team-runtime.ts`、`test/team-membership.test.ts`）**零改动**。

### 目标文件结构（均在 `packages/server/src/services/`）

| 文件 | 职责 | 预估行数 | 来源行号 |
|------|------|---------|---------|
| `team-types.ts` | 类型别名 + 领域接口（`Team`/`TeamMembership`/`TeamMessage`/`TeamInboxItem`/`TeamMessageComment`）+ 导出的 `TeamServiceResult` | ~115 | 10–119 |
| `team-internal.ts` | 所有私有辅助函数：持久化层（路径+IO）、`ok`/`fail`、`isObject`/`asString` 等 parse 工具、view 投影、权限校验、成员解析、`resolveTeamAgentSource`（导出供 barrel 转发） | ~560 | 121–660 |
| `team-manage.ts` | `handleTeamManage`（CRUD + 归档：create/list/get/update/dissolve/archive 相关） | ~260 | 661–918 |
| `team-membership.ts` | `handleTeamMembershipManage`（join/invite/leave/set_role/update_agent/remove） | ~245 | 919–1161 |
| `team-message.ts` | `handleTeamMessageSend` + `handleTeamMessageUpdate` + `handleTeamMessageDelete` + `handleTeamMessageComment` | ~430 | 1162–1587 |
| `team-inbox.ts` | `handleTeamInboxQuery` + `handleTeamInboxDelete` | ~210 | 1254–1459（抽取） |
| `team.ts` | **barrel**：仅 re-export 上述文件的对外符号 | ~20 | 全部替换 |
| `team-runtime.ts` | **不变** | — | — |

> 说明：`team-internal.ts` 集中私有辅助层（store+tools+views+permissions 高度耦合，单独再拆收益低、import 复杂度高，违背最小改动原则）。8 个 handler 按功能域归为 4 个文件（manage/membership/message/inbox），每文件 200–430 行，可独立变化。

## 依赖关系（无循环）

```
team-types.ts         （纯类型，零依赖）
       ↑
team-internal.ts      （依赖 types + json-store + agent/chat/workflow）
       ↑
team-manage.ts ┐
team-membership.ts ├─→  各依赖 team-internal + team-types
team-message.ts ├─
team-inbox.ts  ┘
       ↑
team.ts (barrel)      re-export 全部对外符号
```

handler 之间已确认无交叉调用，拆分后仅单向依赖 `team-internal.ts`。

## 关键技术约束

1. **`isolatedModules: true`**（tsconfig.base.json）→ 类型 re-export 必须用 `export type { ... }`
2. **ESM + `.js` 扩展名** → 所有内部 import 用 `./team-types.js` 形式
3. **无 path alias** → 相对路径导入
4. **`resolveTeamAgentSource` 是导出符号**（被 `team-runtime.ts` 使用）→ 在 `team-internal.ts` 中 `export`，由 barrel 转发

## 实施步骤（小步前进，每步可验证）

3. **新建 `team-manage.ts`**：迁移 `handleTeamManage`（661–918 行）。从 `./team-internal.js` + `./team-types.js` 导入所需。
4. **新建 `team-membership.ts`**：迁移 `handleTeamMembershipManage`（919–1161 行）。
5. **新建 `team-message.ts`**：迁移 `handleTeamMessageSend`/`Update`/`Delete`/`Comment`（1162–1253、1372–1435、1460–1504、1505–1587 行）。
6. **新建 `team-inbox.ts`**：迁移 `handleTeamInboxQuery`/`Delete`（1254–1371、1436–1459 行）。
7. **改写 `team.ts`**：清空原内容，替换为 barrel re-export（如上）。
