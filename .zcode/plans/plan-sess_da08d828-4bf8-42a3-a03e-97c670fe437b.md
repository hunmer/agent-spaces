# 产出区移到节点外部下方独立卡片

## 目标
把 10 个节点的产出区（`<ImageResult>`）从 NodeShell 可滚动表单内移出，作为节点下方独立可折叠卡片渲染，参考 `WorkflowNodeExecutionLog` 的折叠开关 + loader 占位 + 运行时间统计。

## 设计

### 新建 `src/components/nodes/NodeOutput.jsx`
产出卡片组件，结构参考 `workflow-node-execution-log.tsx`：
```
<div mt-1, width=节点宽度, nodrag/nopan>
  <button 折叠栏 onClick={toggle}>
    [Loader2 if running | Check if done | X if error]
    <span>产出</span>
    <span>{耗时/运行中秒数}</span>
    [ChevronUp/Down]
  </button>
  {展开 && (
    status==='running' && 无图 ? <Loader 占位 min-h-[80px]>
    : <ImageResult images/fileName/回调/versions 全套透传 />
  )}
</div>
```
- 默认展开（`useState(true)`）
- 耗时：组件内 `useRef(Date.now())` + `setInterval` 计时；running 时实时秒数，done/error 时定格最终耗时（不改数据层，刷新重置——边缘情况可接受，后续优化可持久化）
- 无产出且非 running：`return null`
- 复用现有 `ImageResult`（网格/添加/删除/清空/版本/MediaGallery 全保留，不改）

### 改 `src/components/nodes/NodeShell.jsx`
1. **正常态分支**（第 206 行）改为 fragment 返回：`<>{原主 div}{<NodeOutput .../>}</>`
   - 参考 `workflow-node.tsx:905` 已验证 ReactFlow 支持 fragment 节点 + 兄弟元素
   - NodeResizer 仍在主 div 内，只 resize 主体；产出卡片独立在下方不受 resize 钳制（正合需求）
2. 用 `ResizeObserver` 测量主 div 宽度，传给 NodeOutput（保证产出卡片与节点同宽）
3. 从 `data` 派生产出 props 传给 NodeOutput：
   - `images = data?.output?.images || []`（与 10 个节点原逻辑一致，不用 outputImages 的 data.images fallback）
   - `fileName = data?.params?.fileName`（覆盖 TextToImage/EditImage 的需求）
   - `status` + 全套 `onAddToAssets/onAddImages/onRemoveImage/onClearImages/versions/activeVersion/onSwitchVersion`
4. **预览态分支**（第 152 行 `outputPreviewEnabled`）**不改**：它是 hover 全屏看图，加产出卡片 redundant

### 删 10 个节点的 `<ImageResult>` 调用
各节点 children 里删除产出调用（NodeShell 统一渲染后避免重复）：
- TextToImageNode.jsx / EditImageNode.jsx（含 fileName，无需再传——NodeShell 从 data.params.fileName 取）
- ImageProcessNode / ImageEditorNode / PixelEditorNode / UiSplitterNode / BBoxViewerNode / CutoutNode / DirectorDeskNode / PhotopeaNode

**不改**：NoteNode（纯文本）、ImageDisplayNode（自实现、不用 NodeShell、无 ImageResult）

## 风险点
- ReactFlow fragment 节点测量：参考 `workflow-node.tsx` 生产环境已验证可行，Handle 用绝对定位相对主 div，不受兄弟元素影响。若实测发现连线锚点偏移，退回方案：各节点自己返回 `<><NodeShell/><NodeOutput/></>`（改动更大但 NodeShell 保持单根）。

## 验收步骤
1. 刷新画布页面
2. 任选一个有产出的节点（如文生图）：确认产出图出现在节点**下方独立卡片**，不再在表单滚动区里
3. 点击产出卡片折叠栏：确认可折叠/展开，默认展开
4. 触发一次生成：确认运行时折叠栏显示 loader + 实时秒数，完成后显示总耗时 + Check 图标
5. 滚动节点表单内容：确认产出卡片不随表单滚动（固定在节点下方）
6. 拖拽 NodeResizer 调整节点大小：确认产出卡片宽度跟随节点，产出卡片高度不被 resize 钳制
