## 用户意图
把 NodeShell 里的【编辑】【抠图】【放大】移到画布级浮层；节点【输入】【输出】gallery 图片改为「单击选中（支持 ctrl 多选）/ 双击预览」；选中图片后浮层显示三个操作按钮。

## 我的假设（用户已确认 / 自行判断）
- **选中作用域**：跨节点全局多选（用户确认）
- **浮层关系**：图片选中时**单独浮层**（顶部居中），原节点多选 toolbar 保持底部居中，两者可共存（用户确认）
- **NodeShell 原按钮**：**完全移除**（用户确认）
- **输入区范围**：仅改 mini-app 本地组件（`src/components/FileUpload.jsx` + `ImageResult` + `UpstreamImageList`）。其他 10+ 节点用的宿主层 `@agent-spaces/ui` FileUpload **不改**（handoff 约束 #28：宿主层改动需重启 web，且影响其他 mini-app）。UpstreamImageList 原本无「单击预览」行为，本次也为其补上「单击选中/双击预览」以保持体验一致。
- **双击行为**：只打开预览，不改选中状态
- **空地点击**：清空图片选中
- **去重策略**：选中 key 用 `${nodeId}::${url}`（应对约束 #24 重复 URL）；导出给操作的 url 数组用 Set 去重

## 成功标准
1. NodeShell 不再显示【编辑】【抠图】【放大】
2. ImageResult（产出区）+ 本地 FileUpload（输入区）+ UpstreamImageList（上游图）缩略图：单击选中/ctrl+单击多选/双击打开 MediaGallery 预览
3. 选中态有视觉反馈（边框高亮 + 勾选角标）
4. 有图片选中时，画布顶部居中浮出 ImageSelectionToolbar，含【编辑】【抠图】【放大】+ 选中数 + 取消选中
5. 点击三个按钮对**所有选中图片的 url 并集**执行对应操作（复用现有 handleProcessImage / handleCutoutCreate / setFormState 回调）
6. 点画布空白/节点/边 清空图片选中

## 实现方案

### 新增 3 个文件

**1. `src/context/ImageSelectionContext.js`**（新建）
React Context，避免 NodeShell→NodeOutput→ImageResult 三层 prop drilling。
```js
// 值：{ isSelected(nodeId,url), toggle(nodeId,url,ctrlKey), clear(), selectedCount }
```

**2. `src/hooks/useImageSelection.js`**（新建）
选中状态 hook，Canvas 层调用。
- `selected: [{ nodeId, url }]`（保持选中顺序）
- `isSelected(nodeId, url)` — some 匹配
- `toggle(nodeId, url, ctrlKey)` — ctrl 时增删；普通点击：已选中且唯一→清空，否则设为唯一
- `clear()` — 清空
- `selectedUrls` — useMemo 去重后的 url 数组（喂给三个操作回调）

**3. `src/components/canvas/ImageSelectionToolbar.jsx`**（新建）
顶部居中浮层（参考 MultiSelectToolbar 结构，定位改 `top-4`）。`selectedCount > 0` 时渲染：
- 文案「已选 N 张」
- 【编辑】→ `onEditImages(selectedUrls)`
- 【抠图】→ `onCutoutCreate(selectedUrls)`
- 【放大】→ `onProcessImage(selectedUrls, 'enhance')`
- 【取消选择】→ `clear()`
- 全部 `nodrag nopan`，按钮样式复用 MultiSelectToolbar 的 `labelBtn`
