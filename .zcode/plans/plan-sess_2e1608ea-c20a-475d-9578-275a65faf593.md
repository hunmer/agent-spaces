## 实现方案

### 1. ChatPanel 头部改造（`packages/web/src/components/ui/chat-panel.tsx`）
- **移除** 写死的 X 关闭按钮（340-342 行）
- `onClose` 改为可选 prop（floating-chat-widget 仍在用，保留兼容）
- **新增** `menuItems?: ReactNode` prop —— 在头部右侧渲染一个 `DropdownMenu`（MoreVertical 图标触发），内容由调用方注入
- agent 切换、设置等常用按钮仍留在 header 外侧（通过现有 `headerActions`）

### 2. 后端「重置 agents.json」API
- **新增 store 函数** `resetAgentsConfig(projectId)`（`mini-app-store.ts`）：
  - 读 `manifest.agents` 种子，若为空抛错
  - 读现有 `agents.json`
  - 对每个种子 agent，按 id 匹配现有配置，**合并保留字段**：`providerId` / `modelProvider` / `modelId` / `runtimeKind`（其余字段如 systemPrompt/suggestions/introduction/tools/avatar/name 用种子值覆盖）
  - `writeAgentsConfig` 落盘
- **新增路由** `POST /:id/agents/reset`（`routes/mini-apps.ts`）→ 调 `resetAgentsConfig`，返回 `{ ok: true }`

### 3. SDK 接口
- 新增 `resetAgents(id): Promise<{ ok: true }>` → `http.post('/api/mini-apps/:id/agents/reset')`

### 4. mini-app 前端（`mini-app-preview.tsx`）
- `useMiniAppAgentChat` hook 新增 `handleResetAgents`：调 `sdk.miniApp.resetAgents(projectId)` → 成功后 `listAgents` 刷新
- **重构 `MiniAppAgentHeaderActions`**：
  - agent 切换 / 设置按钮留在 header 外侧（`headerActions`）
  - 把「清空消息」「查看文件列表」从 headerActions 移除，改为组装成 `menuItems` 传给 ChatPanel
  - menuItems 内额外加「重置 agents.json」项（点击 → 弹 AlertDialog 二次确认 → `handleResetAgents`）
  - 新增一个 reset 确认 AlertDialog（复用现有 AlertDialog 组件，i18n 加词条）
- Popover + Dock 两处 ChatPanel 调用均传入 `menuItems`

### 5. i18n（`locales/{en,zh}/mini-apps.json`）
- 新增词条：`resetAgents`（重置 agents.json）、`resetAgentsConfirm`（确认提示文案，说明保留 provider/model/runtimeKind，重置其余）、`resetAgentsCancel`、`resetAgentsAction`、`menu`（菜单按钮 aria-label）

### 改动文件清单
1. `packages/web/src/components/ui/chat-panel.tsx` — 头部改造 + menuItems prop
2. `packages/server/src/storage/mini-app-store.ts` — resetAgentsConfig

4. `packages/sdk/src/modules/mini-apps.ts` — resetAgents 方法

### 验收
1. 重启 server + 重载 web
2. ChatPanel 头部应无 X 关闭按钮，右侧有 ⋮ 菜单
3. 点菜单 → 下拉显示「清空消息」「查看文件列表」「重置 agents.json」
4. 改某 agent 的 systemPrompt → 点「重置」→ 确认 → systemPrompt 恢复种子值，但 providerId/modelId/runtimeKind 保留
