## 重构计划：按功能拆分 team-management-page.tsx

### 目标
将 597 行单文件拆为 4 个文件，主文件降到约 280 行（状态/数据加载/对话框编排），功能完全不变。

### 拆分方案

#### 1. 新建 `team-management-utils.ts`
提取以下纯常量和工具函数（外部无引用，已验证安全）：
- `PANEL_ID_LIST` / `PANEL_ID_CHAT` / `PANEL_ID_DETAIL`
- `LAYOUT_KEY` / `DEFAULT_LAYOUT`
- `loadSavedLayout()`
- `extractAgentRunIds(workflow)`
- `formatTime(value)`

#### 2. 新建 `team-list-panel.tsx`
提取左栏团队列表面板（原 394-485 行），作为 `<TeamListPanel>` 子组件：
- Props（按依赖最小化传递）：
  - `error: string` — 顶部错误条
  - `loadingTeams: boolean` / `loadingArchived: boolean`
  - `canCreateTeam: boolean`
  - `teams: TeamView[]` / `archivedTeams: TeamView[]`
  - `selectedTeamId: string`
  - `availableAgents` — 已过滤的 agent 列表
  - 回调：`onCreateTeam` / `onImportFromWorkflow` / `onSelectTeam` / `onEditTeam` / `onDissolveTeam` / `onRestoreArchived` / `onDeleteArchived` / `onClearArchived`

#### 3. 新建 `team-detail-panel.tsx`
提取右栏详情面板（原 516-557 行），作为 `<TeamDetailPanel>` 子组件：
- Props：
  - `selectedTeam: TeamView | null`
  - `teamDetail: TeamDetail | null`
  - `selectedActorId: string`
  - `availableAgents`
  - `activeSessionId?: string`
  - 回调：`onEditTeam` / `onDissolveTeam` / `onRefreshDetail`

#### 4. 重写 `team-management-page.tsx`
- 从新模块 import 工具函数和子组件
- 保留：全部 state、useEffect 数据加载、所有 CRUD 操作函数（openCreateDialog / submitTeam / dissolveTeam / loadTeams 等）、布局编排（ResizablePanelGroup）、CreateTeamDialog / WorkflowListDialog
- JSX 中左栏替换为 `<TeamListPanel ... />`，右栏替换为 `<TeamDetailPanel ... />`

### 安全保证
- **不改变任何行为**：状态管理、数据流、轮询逻辑、对话框逻辑全部保留在主组件；子组件是无状态展示组件，只接收 props 和回调
- **不改命名**：对外导出的 `TeamManagementPage` 和 `TeamManagementPageHandle` 保持不变
- **类型保留**：所有 props 类型显式声明，沿用现有 `TeamView` / `TeamDetail` / `TeamFormDefaults` 等类型
- 移动时保留原文件的注释（如三栏布局持久化注释、extractAgentRunIds 的兼容性注释）
