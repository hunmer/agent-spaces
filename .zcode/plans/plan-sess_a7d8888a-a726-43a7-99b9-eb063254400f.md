# Team 成员消息对话框 实现方案

数据源：**inbox 投递 (deliveries.json)**，与现有未读数徽章语义一致。右侧用 `Markdown` 渲染消息正文，消息卡片支持标记已读/未读 + 删除单条投递。

## 一、后端（`packages/server`）

### 1. `src/services/team.ts`
- **`handleTeamInboxQuery` 的 list 分支**：
  - 新增 `recipient_agent_id` 入参。若提供，用它作为收件人过滤；否则保持现有行为（默认 = `actor_agent_id`）。
  - **权限**：当 `recipient_agent_id` 与 `actor_agent_id` 不同时，要求 actor 是该 `team_id` 的 active 成员，否则 `PERMISSION_DENIED`（防止泄露任意 agent 的全局收件箱）。
  - **附带正文**：对过滤后的结果，按 teamId 加载该 team 的 `listMessages()` 构建 `Map<messageId, TeamMessage>`，给每个 inbox item 注入 `body` / `body_format` / `subject`（来自关联 message），供前端 markdown 渲染。
- **新增 `export function handleTeamInboxDelete(input)`**：
  - 入参 `delivery_id` + `actor_agent_id`。
  - 复用 `findDeliveryContext(deliveryId)`；找不到 → `DELIVERY_NOT_FOUND`。
  - 权限：收件人本人，或该 team 的 owner/admin（复用 `getActiveMembership`，与 `handleTeamMessageDelete` 一致）。
  - `saveDeliveries(team.id, deliveries.filter(d => d.id !== deliveryId))`。
  - 返回 `{ delivery_id, team_id }`。

### 2. `src/routes/team.ts`
- `teamInboxRouter.get('/')` list：query 透传 `recipient_agent_id`。
- 新增 `teamInboxRouter.delete('/:deliveryId', ...)` → `handleTeamInboxDelete({ delivery_id, actor_agent_id: body?.actor_agent_id ?? query.actor_agent_id })`。
- `sendResult` 的 404 code 列表已含 `DELIVERY_NOT_FOUND`，无需改。

## 二、SDK（`packages/sdk/src/modules/team.ts`）
- 新增视图类型 `TeamInboxItemView`（含 `delivery_id`/`message_id`/`team_id`/`sender_agent_id`/`inbox_status`/`read_at`/`sent_at`/`subject`/`body`/`body_format`/`priority` 等）与 `TeamInboxListResponse`（`inbox_items` + `summary.unread_count_estimate`）。
- 新增方法（走 `unwrap`）：
  - `listInbox(params: { actor_agent_id; team_id; recipient_agent_id?; unread_only?; page_size? })`
  - `updateInboxStatus(deliveryId, { actor_agent_id, inbox_status })` → PATCH
  - `deleteInboxItem(deliveryId, actor_agent_id)` → DELETE

## 三、前端（`packages/web`）

### 1. 新建 `src/components/teams/team-inbox-dialog.tsx`
- Props：`{ open, onOpenChange, teamId, actorAgentId, members: TeamMembershipView[], agents, onChanged }`。
- **布局**：`Dialog` + `DialogContent`（`sm:max-w-4xl`，左右两栏 `flex`）。
  - **左栏**（固定宽 ~240px，可滚动）：成员列表，每项显示头像/名字 + 未读数 Badge（复用 `TeamMemberRow` 的 select variant，或精简渲染）。默认选中第一个有未读的成员。
  - **右栏**（flex-1，可滚动）：选中成员后调 `sdk.team.listInbox({ team_id, recipient_agent_id, actor_agent_id })`，按 `sent_at` 倒序渲染消息卡片。
- **消息卡片**：标题行（发件人 + 时间 + 状态点），正文用 `<Markdown content={body} />` 渲染；右上角两个按钮：标记已读/未读（`MailOpen`/`Mail`）+ 删除（`Trash2`）。
  - 标记已读：`sdk.team.updateInboxStatus(deliveryId, { actor_agent_id, inbox_status: 'read'|'unread' })`。
  - 删除：`sdk.team.deleteInboxItem(deliveryId, actor_agent_id)`。
  - 任一操作后重新拉取该成员列表，并 `onChanged()` 通知父组件刷新未读数。
- 复用 `team-chat-panel.tsx` 的 Dialog 结构与错误提示样式。

### 2. 修改 `src/components/teams/team-member-row.tsx`
- Props 新增 `onInboxOpen?: () => void`。
- 第 108~111 行未读 Badge：当 `onInboxOpen` 存在时，用 `<button onClick={stopPropagation + onInboxOpen}>` 包裹 Badge（带 hover 高亮 + title「查看消息」）。

### 3. 修改 `src/components/teams/team-member-list.tsx`
- 新增 state `inboxOpen: boolean`。
- 给 `TeamMemberRow` 传 `onInboxOpen={() => setInboxOpen(true)}`（对所有成员都可打开，因为对话框内可切换成员）。
- 渲染 `<TeamInboxDialog open={inboxOpen} ... onChanged={onChange} />`（复用现有 `members`/`agents`/`teamId`/`actorAgentId`）。

## 四、i18n
新对话框文案按现有 `useTranslations("teams")` 模式，在 `teams.inbox.*` 下补 key（成员消息 / 标记已读 / 标记未读 / 删除 / 暂无消息 等）。若 locale 文件结构不便扩展，则退化为硬编码简体中文（保证不破坏现有 i18n）。

## 五、验收
- `pnpm exec tsc --noEmit -p packages/server/tsconfig.json`
- `pnpm exec tsc --noEmit -p packages/web/tsconfig.json`
- 手动：打开 team 详情 → 成员列表点未读徽章 → 弹出对话框 → 左侧切换成员看右侧消息 → 点已读/删除生效、未读数同步刷新。

## 六、最小改动 / 不做的事
- 不动 runtime 聊天消息（messages.json）那套。
- 不加批量已读、不加 inbox 归档。
- 删除只删单条投递，不影响 message 本体和其他收件人。
