## 实施计划：雪碧图拆分节点 · 增加裁切 + 网格模式

### 改动范围
**只改一个文件**：`packages/server/agent-spaces-data/mini-apps/game-asset-canvas/src/components/UiSplitterDialog.jsx`
- 不动节点组件、不动宿主层、不加 vendor 依赖
- 刷新即生效（mini-app src 层）

### 一、新增「裁切」功能

**1. 新增 state/ref**
- `cropModeRef` (ref, bool)：是否处于裁切拉框模式
- `cropDraftRef` (ref, fabric.Rect|null)：裁切范围临时框
- `cropBox` (state)：`{x,y,width,height} | null`，松开鼠标后保留，驱动确认条
- 复用现有 `startRef` / `drawingRef`（但用独立标志区分，避免与切片拉框冲突）

**2. 工具条新增按钮**（放在 undo/redo 之后的独立分组）
- 「✂️ 裁切」toggle 按钮，激活后高亮（`variant={cropMode?'default':'outline'}`），状态栏提示「拉框选择裁切范围，松开后点【应用裁切】」

**3. 交互逻辑**（改 `bindFabricEvents`）
- `cropModeRef=true` 时，`mouse:down` 在空白处启动裁切拉框（橙色虚线框，`kind='crop'`，`strokeDashArray:[6,4]`），**不进切片 undo 栈**
- `mouse:move` 更新裁切框尺寸
- `mouse:up` 保留裁切框（不删），设 `cropBox`，画布上方显示确认条
- 裁切模式下禁用切片拉框与参考线交互（互斥）

**4. 确认条 UI**（画布顶部浮动，`cropBox` 非空时显示）
- 显示「裁切 {w}×{h}」+【✅ 应用裁切】/【✖ 取消】
- 应用流程：
  1. `exportBox(source.imageData, cropBox, { transparent:false })` → canvas → blob
  2. `uploadFile(blob)` 拿 http URL
  3. **替换原图**：
     - 若激活图来自 `uploadedImages`（在节点 `data.uploadedImages` 里）→ 调 `onUpdate({ uploadedImages: newUrls })` 替换该位置
     - 若激活图来自上游 `data.images`（只读）→ 裁切结果**追加**到 `uploadedImages`（语义：另存为新上传图），状态栏提示
  4. `loadImageSource(newUrl)` 重建该图 `source`（含新 imageData/canvas）
  5. 刷新 fabric 背景图 + `fitToStage`
  6. **清空该图 undo/redo 栈 + rects**（source 变了，旧坐标失效），清 `splitData`
  7. 清除裁切框，退出裁切模式
- 取消：删除裁切框，`cropBox=null`

### 二、新增「网格模式」

**1. 新增 state/ref**
- `gridMode` (state, bool) / `gridModeRef` (ref 同步)
- `gridCols` (state, 默认 2) / `gridRows` (state, 默认 2)
- `vGuidesRef` (ref, number[])：垂直参考线 x 坐标（图片像素）
- `hGuidesRef` (ref, number[])：水平参考线 y 坐标
- `showGridPopover` (state, bool)：网格参数 popover 开关

**2. 工具条新增按钮**
- 「# 网格模式」toggle（与「✂️ 裁切」「框选/选择」并列），点击切换 `gridMode`
- 旁边一个小「⚙」按钮（或点网格按钮弹 popover），popover 内含 cols/rows NumberInput

**3. 进入网格模式**（`enterGridMode`）
- 清空当前图所有切片框（`kind='slice'`），pushHistory 记录
- 按 `gridCols`/`gridRows` 在图片宽高均分位置生成参考线：
  - 垂直线：`imgWidth * i/cols`（i=1..cols-1）
  - 水平线：`imgHeight * j/rows`（j=1..rows-1）
- 参考线为 `fabric.Line`，`kind='guide'`，`stroke:'#eab308'`，`strokeWidth:2`，`selectable:true`，`hasControls:false`，`hasBorders:false`
  - 垂直线 `lockMovementY:true, lockScalingY:true, lockRotation:true`（只能左右移）
  - 水平线 `lockMovementX:true, lockScalingX:true, lockRotation:true`（只能上下移）
- 隐藏右侧切片实时列表，显示【🔲 网格拆分】按钮 + cols/rows 显示

**4. 参考线拖动**（复用 fabric `object:moving`/`object:modified`）
- `object:moving` 时若 target 是 guide：clamp `left`/`top` 到 `[0, imgWidth]`/`[0, imgHeight]`，实时同步到 `vGuidesRef`/`hGuidesRef`
- 网格模式下切片拉框/裁切都禁用（参考线独占交互）

**5. cols/rows 变化**（popover 内 NumberInput onChange）
- 重新生成参考线（保留能保留的旧坐标，多余的丢弃，不足的均分补齐；简单起见：直接按新行列数重新均分，丢弃用户已调整的位置——在 popover 内调整视为"重置网格"）
- 重排参考线到画布

**6. 退出网格模式**（`exitGridMode(keepSlices)`）
- 清除所有参考线
- 恢复右侧切片列表 + 保存按钮
- 若 `keepSlices=false`（直接退出未拆分）：保留进入前的空切片状态

**7. 【网格拆分】按钮**（`splitByGrid`）
- 收集垂直切割点：`[0, ...vGuidesRef.sort(), imgWidth]`
- 收集水平切割点：`[0, ...hGuidesRef.sort(), imgHeight]`
- 双重循环生成 box：`{x:vx[i], y:hy[j], width:vx[i+1]-vx[i], height:hy[j+1]-hy[j]}`
- 过滤掉 `width<2 || height<2` 的无效格子
- `pushHistory()`，把所有 box 加入为切片框（`kind='slice'`）
- 调用 `exitGridMode(true)` 退出网格模式 → `renderList()` 显示切片 → 状态栏「已按网格拆分为 N 个切片」
- 之后用户可正常用切片保存流程

### 三、互斥与模式优先级

裁切模式、网格模式、切片拉框模式三者互斥：
- 进入裁切 → 自动退出网格
- 进入网格 → 自动退出裁切 + 清切片框
- 网格模式下「框选/选择」toggle 失效（disabled）

### 五、坑点与约束（遵守 handoff 规范）

1. **裁切替换上游图是只读**：上游图只能"另存为上传图"追加，不能原地替换（已在流程里分流处理）。
2. **裁切后必须清 undo/redo + splitData**：source 变化导致旧 rects 坐标失效，遵守持久化规范「输入图集合变化时清旧数据」。
3. **参考线用 `kind='guide'` 与 `kind='slice'` 区分**：现有 `rects()` 过滤 `kind==='slice'`，参考线不会被误计入切片；`snapshot()`/`renderList()` 无需改动。
4. **参考线单轴锁定**：用 fabric v5 的 `lockMovementX/Y`，不自己实现 pointer 拖动（最小改动）。
5. **网格模式不持久化**：cols/rows/参考线位置是运行时状态，关闭对话框即丢失（与 drawMode 一致惯例）；如需持久化后续扩展。
6. **裁切框/参考线不受 Delete 键删除**：现有 `deleteSelectedRects` 只删 `kind==='slice'`，guide/crop 自动豁免。

### 六、验收步骤

1. 打开雪碧图拆分节点 → 上传/连入一张图 → 点【🧩 打开拆分编辑器】
2. **裁切**：点「✂️ 裁切」→ 在图上拉框 → 点【✅ 应用裁切】→ 画布背景变为裁切后的图，切片框清空，撤销栈重置
3. **网格**：点「# 网格模式」→ 弹 popover 输入 cols=4 rows=3 → 画布出现 3 条垂直 + 2 条水平黄色参考线，均分
4. **拖动参考线**：长按一条垂直线左右拖 → 只能左右移动，不能上下；松开后位置保留
5. **网格拆分**：点【🔲 网格拆分】→ 参考线消失，右侧列表出现按网格切分的切片（如 4×3=12 张）→ 点【💾 保存全部】正常上传
6. **互斥**：网格模式下「框选/选择」按钮 disabled；进入裁切自动退出网格
7. **持久化**：裁切后关闭对话框重开，显示的是裁切后的新图（uploadedImages 已替换）
