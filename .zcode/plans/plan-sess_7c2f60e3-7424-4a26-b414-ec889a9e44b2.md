# 骨骼编辑器 AI 换肤功能 实现方案

## 目标
把 `G:\spine-animation-ai-workspace\spine-animation-ai\reskin-app` 的 Python 后端换肤 pipeline 迁移到 game-asset-canvas mini-app,**除 SAM 外的后端逻辑全部前端化(JS)**。SAM 用 mini-app 的 rembg 插件实现。新增皮肤生成历史面板 + 实时换肤日志。

## 架构决策(已与用户确认)
- **纯逻辑(atlas 解析/pack/repack/skin_writer/Canvas 合成)放 mini-app 主应用** —— 可直连 `window.AgentSpaces.callPluginTool/uploadFile`。
- **iframe 只做预览** —— 经 postMessage 接收新 atlas png 做热加载预览(`baseTexture.setResource`,UV 不动)。
- **AI 编辑用 `nano-banana` 插件**(`nano_banana_edit_image`,封装 Gemini,语义与原后端一致)。
- **SAM 分割用 `rembg` 插件**(`rembg_sam_segment`,point prompt → 抠图 PNG)。
- **MVP 仅 atlas 方法 + rembg SAM 分割**(exploded/bg_components 后续迭代)。
- **两种应用方式都要**:热加载预览 + 导出三件套(.skel+.atlas+.png)。

## 换肤 Pipeline(JS 实现,对译自 Python 后端)

```
① 取素材：spine-editor canvas 截图(snapshot) + 原 atlas sheet PNG + 原 .atlas 文本 + spine JSON
   ↓
② 合成 composite：[snapshot | atlas_sheet] 左右并排，白底，居中对齐
   (对译 atlas_compose.build_atlas_composite，Canvas drawImage 合成)
   ↓
③ Gemini 重绘：callPluginTool('workflow.nano-banana','nano_banana_edit_image',
   {image: compositeUrl, prompt: ATLAS_RESKIN_PROMPT.format(userPrompt)})
   → 返回重绘后的 composite PNG URL
   ↓
④ 分割回切：对每个 atlas region，调 rembg SAM 抠图
   - 解析原 .atlas 拿 region bboxes {name,x,y,w,h,rotate}
   - 从重绘 composite 裁出 atlas 半边 → resize 到原 sheet 尺寸
   - 逐 region：按 bbox 裁出 region PNG → rembg_sam_segment(SAM point prompt 取 bbox 中心) → 抠好的透明 PNG
   - (侵蚀：可选，用 Canvas 像素操作 erode alpha 边缘，去除 Gemini 的白边)
   ↓
⑤ repack：把所有 region PNG 用 shelf packing 打包成新 atlas sheet (Canvas 合成 + 写 .atlas 文本)
   (对译 make_atlas.pack + atlas_repack.repack_atlas)
   ↓
⑥ skin_writer：往 spine JSON 的 skins 数组加新 skin(继承 default 的 attachment meta，只换 region name)
   (对译 skin_writer.add_skin)
   ↓
⑦ 产出：新 atlas PNG + 新 .atlas + 新 spine JSON(含新 skin) + 原始 .skel
   → 热加载预览 + 历史记录 + 可导出三件套
```

## 改动清单

### A. 新增 mini-app 主应用工具模块(`src/utils/reskin/`,新建目录)

纯 JS 实现,无第三方库依赖(图像用 Canvas 2D):

| 文件 | 职责 | 对译自 | 行数估 |
|---|---|---|---|
| `atlasReader.js` | 解析 Spine .atlas 文本 → regions[{name,x,y,w,h,rotate,origW,origH}] + sheet 尺寸 | `spine/atlas_reader.py` | ~130 |
| `atlasPacker.js` | shelf bin-packing(按高排序→换行→pow2)+ nextPow2 工具 | `scripts/make_atlas.py:pack` | ~40 |
| `atlasRepack.js` | 把 region PNG 集合打包成新 sheet(Canvas drawImage)+ 写 .atlas 文本;`_safe(name)` 折叠 `/` | `spine/atlas_repack.py` | ~90 |
| `skinWriter.js` | 往 spine JSON 加 skin(deepClone + 继承 default attachment + 换 region name);兼容 3.8 dict / 4.0 array | `spine/skin_writer.py` | ~70 |
| `reskinPipeline.js` | 串联 ①~⑥ 全流程,接受日志回调 `onLog(step,msg,data)` | `reskin/pipeline.py` + `atlas_rebake.rebake_skin` | ~200 |
| `compositeBuilder.js` | `[snapshot|atlas]` 左右合成(Canvas),返回 layout_map | `reskin/atlas_compose.py` | ~50 |
| `canvasUtils.js` | dataUrl↔Image↔Canvas 互转,Canvas crop/paste/erode alpha | (新建,替代 PIL) | ~80 |

**关键实现点**:
- 图像合成全部用 `OffscreenCanvas`/`<canvas>` + `drawImage`,RGBA 用 `getImageData`/`putImageData`。
- `_safe(name)`:`/ \` 空白 → `_`,与 Python 版一致(保证 name_map round-trip)。
- region 裁剪旋转:复刻 `_crop_region_rotated`(rotate 90/180/270 用 Canvas `rotate` transform)。
- 侵蚀(去白边):可选用 Canvas 像素遍历 erode alpha,半径按 region 边长缩放(对译 `settings.erosion.px_for_side`);MVP 可先关闭。

### C. 扩展 SpineEditorDialog.jsx(postMessage 桥接)

新增 props 与消息:

**父→iframe(新增)**:
- `spine:request-snapshot` → iframe 截当前 canvas → 回 `spine:snapshot {dataUrl}`(用于换肤的 snapshot 输入)
- `spine:replace-atlas` `{pngDataUrl, [atlasDataUrl]}` → iframe 用 `baseTexture.setResource()` 热加载新 sheet 预览(无需重载 .skel)
- `spine:get-atlas-info` → iframe 回 `spine:atlas-info {sheetW, sheetH, regionCount}`(可选,用于校验)

**iframe→父(新增)**:
- `spine:snapshot {dataUrl}` — canvas 截图回传
- `spine:atlas-replaced {name}` / `{error}` — 热加载结果回执

3. **main.js**:message 监听新增 `spine:request-snapshot` / `spine:replace-atlas` / `spine:get-atlas-info` 分支。
4. **改完必须重建**:`cd spine-editor-build && npm run build`,把 `dist/` 内容覆盖到 `src/vendor/spine-editor-web/`(index.html + assets/)。

## 日志与历史

**实时日志**(ReskinPanel.jsx):
- pipeline 每步通过 `onLog(step, msg, data)` 回调,实时 append 到日志区(带时间戳、步骤图标、耗时)。
- 步骤:①取素材 ②合成composite ③Gemini重绘(显示耗时) ④分割回切(N/总数进度) ⑤repack ⑥skin JSON ⑦完成。
- 错误步骤红色高亮 + 显示 error message。

**皮肤历史**(SkinHistoryList.jsx):
- 每次换肤成功后,记录一项:{name, prompt, timestamp, thumbnailUrl, assets:{skel, atlas, png, spineJson}}。
- 存 localStorage(键 `spine-reskin-history:<spineName>`),按 spine 角色分组。
- 点击历史项 → 触发 `replace-atlas` 热加载预览,并设为当前可导出皮肤。

## 风险与对策

| 风险 | 对策 |
|---|---|
| Gemini 重绘后 region 位置漂移 → SAM 抠图错位 | 复刻原后端的「裁 region 后再 SAM」逻辑(不是整图 SAM),并用原 atlas bbox 约束 |
| nano-banana 返回 URL 而非 inline data | `nano_banana_edit_image` 返回 `data.images[]`(http URL),经 `proxyImageUrl`+fetch 转 dataUrl 即可 |
| rembg SAM 无 bbox prompt,只有 point | 用 region bbox 中心点做 point prompt(label=1 前景);若精度不足,改用 box prompt(rembg 支持 `{"type":"box","data":[x1,y1,x2,y2]}`) |
| atlas sheet 尺寸非 pow2 | shelf pack 输出强制 pow2,pixi-spine 不强制要求 pow2(Linear filter 即可) |
| region 含 `/`(中文 atlas 如 `默认/头2`) | `_safe()` 折叠 + name_map round-trip(已验证逻辑,Python 版同款) |
| 侵蚀去白边精度 | MVP 先关闭侵蚀,验证基础流程;后续用 Canvas 像素遍历 erode alpha 补上 |

## 实施顺序(分 5 步,每步可独立验证)

1. **Spine 处理工具模块**(`src/utils/reskin/` 全部)— 纯 JS,可单测:解析一个真实 .atlas → repack → 比对 region 数量与 Python 版一致。
2. **postMessage 扩展 + vendor SPA 热加载** — 改 SpineLoader/SpineEditorApp/main.js,重建产物。验证:父端发 `replace-atlas` → iframe 角色贴图变化。
3. **换肤 pipeline 串联**(`reskinPipeline.js` + nano-banana + rembg)— 验证:输入三件套+prompt → 输出新 atlas PNG。
4. **ReskinPanel + SkinHistoryList UI** — 换肤面板 + 日志 + 历史。验证:端到端换肤 + 历史点击应用。
5. **节点集成 + 三件套导出** — 换肤产出回填节点。验证:节点 output 含新三件套 URL。
