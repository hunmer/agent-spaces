## 修复目标
消除 `game-asset-canvas/src/` 下三个控制台错误（button 嵌套 button ×2 + asChild 未识别），它们源于同一处根因。

## 根因
`PopoverTrigger`（`@agent-spaces/ui`，底层 Base UI `@base-ui/react` v1.4.1）不支持 `asChild`，仅支持 `render` prop。`ExecutionQueuePopover.jsx` 错误地用 `<PopoverTrigger asChild>` 包裹原生 `<button>`，导致 Base UI 自己又渲染一个 `<button>` 套在外面，且 `asChild` 作为未知 prop 泄漏到 DOM。

## 改动（仅 1 个文件，1 处）
文件：`packages/server/agent-spaces-data/mini-apps/game-asset-canvas/src/components/ExecutionQueuePopover.jsx`（约第 21–35 行）

将：
```jsx
<PopoverTrigger asChild>
  <button type="button" className="..." title="执行队列">
    <span>📋</span>
    <span>执行队列</span>
    {runningCount > 0 && (<span className="...">{runningCount}</span>)}
  </button>
</PopoverTrigger>
```
改为（按钮元素及其 children 原样移入 `render` prop，参照同目录 `WorkspaceSwitcher.jsx:66-78` 的 Base UI 范式）：
```jsx
<PopoverTrigger
  render={
    <button type="button" className="..." title="执行队列">
      <span>📋</span>
      <span>执行队列</span>
      {runningCount > 0 && (<span className="...">{runningCount}</span>)}
    </button>
  }
/>
```

## 执行步骤
1. 读取 `ExecutionQueuePopover.jsx` 确认第 21–35 行确切文本。
2. 用 Edit 做上述最小替换（不改动 className、children、PopoverContent 内逻辑）。

## 成功标准
- 三个控制台错误全部消失。
- 执行队列按钮点击后 Popover 正常弹出、角标（runningCount）显示正常。
