# 文案库 (copywriting)

> 一站式文案管理工具，支持文本 / 音频 / 视频三种类型，自动转写音视频为可检索文字。

## 这是什么

文案库用来集中管理你收集到的所有文案素材。你可以手动输入文字，也可以上传音频或视频文件，系统会自动调用语音识别服务把音视频转写成文字，统一以瀑布流卡片的形式展示，并通过侧边栏快速筛选。

## 三种文案类型

| 类型 | 录入方式 |
| --- | --- |
| 文本 | 手动填写标题与正文 |
| 音频 | 上传音频文件，自动转写为文字 |
| 视频 | 上传视频文件，自动转写为文字 |

## 使用流程

### 新增文本文案
1. 点击右上角「新建」按钮
2. 选择「文本」类型
3. 填写标题、内容与标签
4. 保存

### 新增音视频文案
1. 点击右上角「新建」按钮
2. 选择「音频」或「视频」类型
3. 上传文件（拖拽或点击均可）
4. 文件会自动上传到云存储（OSS / COS），并发起语音识别
5. 转写完成后，文案卡片状态变为「完成」，正文即为识别结果

### 编辑与删除
- 点击卡片右上角的菜单可编辑、删除或重试转写
- 重试功能：转写失败时可一键重试，无需重新上传文件

## 筛选与检索

左侧边栏提供多种筛选维度：

- **关键词搜索**：即时匹配标题与正文
- **类型筛选**：文本 / 音频 / 视频
- **标签筛选**：按标签过滤
- **时长排序**：按音视频时长排序

筛选偏好会自动保存，下次打开应用时恢复。

## 播放音视频

点击卡片上的「播放」按钮，会在弹窗中加载音视频播放器，可全屏观看 / 收听。

## 存储设置

右上角齿轮可切换云存储方案：

- 阿里云 OSS（默认）
- 腾讯云 COS

切换后，后续上传的文件将使用新的云存储方案。

## 转写状态

每张卡片会显示当前转写状态：

| 状态 | 含义 |
| --- | --- |
| 转写中 | 语音识别进行中，请稍候 |
| 完成 | 转写成功，正文已可查看 |
| 失败 | 转写失败，可点击重试 |

## 数据存储

所有文案数据保存在本地 SQLite 数据库中，包括：

- 标题、内容、标签
- 原始音视频文件路径
- 转写后的文字内容
- 时长、状态、创建时间等元信息

切换设备或清除本地数据后无法恢复，请定期导出备份。

## 常见问题

**转写一直停在「转写中」？**
请检查网络与服务连通性。如长时间无响应，可删除该条重建，或检查阿里云 ASR 插件配置。

**上传文件失败？**
请确认在存储设置中选择了已配置好的云存储方案，并确保对应插件的访问密钥已正确填写。

**音视频无法播放？**
请检查原始文件是否被移动或删除，必要时重新上传。
