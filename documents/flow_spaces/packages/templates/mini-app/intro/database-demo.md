# 代码片段管理器 (database-demo)

> 一个面向开发者的代码片段管理工具，演示 mini-app 宿主提供的三种数据存储能力：SQLite 结构化存储、JSON 配置持久化、JSON 数据导出。

## 这是什么

代码片段管理器用来集中保存你日常开发中常用的代码片段。你可以按语言分类、关键词搜索、一键复制、编辑或删除。同时它也是 mini-app 三种数据能力的演示项目，帮助你了解不同数据存储方式的使用场景。

## 主要能力

| 能力 | 说明 |
| --- | --- |
| 结构化存储 | 片段保存在 SQLite 数据库，支持增删改查 |
| 语言过滤 | 按编程语言筛选片段 |
| 关键词搜索 | 搜索标题、标签、代码内容 |
| 一键复制 | 卡片上点击复制即可把代码写入剪贴板 |
| 批量导入 | 一次性导入多条片段（事务原子提交） |
| 数据导出 | 把全部片段导出为 JSON 文件 |
| 偏好记忆 | 上次选择的语言会自动恢复 |

## 使用流程

### 新建片段
1. 点击右上角「新建」按钮
2. 填写标题、选择语言、添加标签
3. 在代码编辑区粘贴或输入代码
4. 保存

### 查找片段
- 在顶部搜索框输入关键词（搜索标题、标签、代码内容）
- 通过语言下拉菜单按语言过滤

### 编辑与删除
- 卡片右上角有「编辑」和「删除」按钮
- 编辑会打开表单，修改后保存即可

### 复制代码
- 卡片上「复制」按钮可把代码写入剪贴板

### 批量导入
- 在工具栏点击「导入示例」可演示批量导入流程
- 导入会作为一个事务原子提交，要么全部成功要么全部回滚

### 导出数据
- 点击「导出 JSON」会把所有片段导出为 JSON 文件
- 导出文件可作为备份，也可用于迁移到其他环境

## 数据存储

| 数据 | 存储方式 | 位置 |
| --- | --- | --- |
| 片段结构化数据 | SQLite | `data/db/snippets.sqlite` |
| 过滤语言偏好 | JSON config | `configs/settings.json` |
| 导出快照 | JSON data | `data/snippets-export.json` |

刷新或重启应用时，SQLite 与 JSON config 中的数据会自动恢复。导出文件是独立快照，可手动下载保存。

## 支持的语言

系统支持多种主流编程语言，完整列表参见 `utils/settings.js` 的 `LANGUAGES` 常量。可在新建片段时自由扩展。

## 常见问题

**搜索没结果？**
请检查语言过滤与关键词是否同时生效，可清空过滤条件重新搜索。

**导出按钮没反应？**
请检查浏览器是否允许下载文件，必要时调整浏览器下载设置。

**导入示例失败？**
通常是因为数据库中存在冲突数据，可尝试先清空片段再导入。
