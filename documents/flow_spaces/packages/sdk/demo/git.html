Git · 仓库操作

选择工作区

Git 接口依赖 workspaceId，先选择一个已绑定 Git 仓库的工作区。

状态（status）

sdk.git.status(workspaceId) —— 当前分支 / 暂存 / 改动文件。

结果将显示于此

提交历史（log）

sdk.git.log(workspaceId)

结果将显示于此

分支（branches）

sdk.git.branches(workspaceId)

结果将显示于此

提交（commit）

sdk.git.commit(workspaceId, message) —— 提交所有暂存改动。

结果将显示于此
