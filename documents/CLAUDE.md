# documents

Docusaurus 3 文档站点。包含博客、API 文档等。端口 3001。

## 约定

- `docusaurus start --port 3001` 开发。
- React 19 + TypeScript 6。
- 博客配置在 `blog/`，作者和标签在 `blog/authors.yml`、`blog/tags.yml`。
