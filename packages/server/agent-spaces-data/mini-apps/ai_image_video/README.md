# AI 创作 (ai_image_video)

> 一站式 AI 图像与视频创作工具，支持文生图、图生图、图片编辑、图生视频、扩图、视频编辑、数字人七种创作模式。

## 这是什么

AI 创作是一个集成多种主流 AI 模型的可视化创作工作台。你可以在左侧表单中描述创作需求，右侧按时间顺序查看所有生成结果，并通过卡片菜单一键发起二次创作。

## 主要能力

| 模式 | 说明 | 输入 |
| --- | --- | --- |
| 文生图 | 用文字描述生成图片 | 文字描述 |
| 图生图 | 参考已有图片生成新图 | 1-4 张参考图 + 描述 |
| 图片编辑 | 局部修改、风格迁移、物体增删 | 1-9 张图（依提供商） + 描述 |
| 图生视频 | 把静态图片变成动态视频 | 1 张图片 + 描述 |
| 扩图 | 智能扩展图片边界 | 1 张图片 + 方向参数 |
| 视频编辑 | 修改已有视频内容 | 1 个视频 + 可选参考图 |
| 数字人 | 让视频中的人物说话/动作 | 1 个视频 + 1 个音频 |

## 支持的 AI 提供商

- **MiniMax**：图生视频（异步轮询，自动等待生成完成）
- **即梦 (Jimeng)**：文生图
- **阿里云 AI**：文生图、图生图、图片编辑、扩图、视频编辑、数字人
- **OpenAI**：文生图、图生图、图片编辑

## 使用流程

1. 在左侧顶部 Tab 选择创作模式
2. 选择提供商与模型
3. 上传所需的图片 / 视频 / 音频素材（如需要）
4. 填写提示词（prompt）
5. 点击「生成」按钮发起任务
6. 在右侧按日期+模式+提供商分组查看结果
7. 点击结果卡片底部 `⋮` 菜单可下载、二次创作或删除

## 二次创作

对任意历史结果点击卡片底部 `⋮` 菜单，可以一键：

- 重新生成同样的内容
- 把图片作为图生图的输入
- 把图片作为图生视频的输入
- 对图片执行扩图 / 图片编辑
- 对视频执行视频编辑

系统会自动切换模式、保留原提供商、预填素材，你只需补一句描述再点生成。

## 并发任务

提交按钮始终可用，你可以连续发起多个生成任务。生成按钮旁的红色角标会显示当前正在运行的任务数，点击可查看每个任务的进度与状态。

## 上传与云存储

部分模式（图生视频 / 扩图 / 视频编辑 / 数字人）需要公网可访问的文件 URL。系统会自动把本地文件转存到阿里云 OSS 或腾讯云 COS，再传给 AI 服务。

可在「上传设置」中选择云存储提供商，并控制是否启用自动转存。首次使用前请在插件配置中填写相应云存储的访问密钥。

## 历史记录

所有生成结果会自动保存到本地配置文件中。关闭页面或重启后，历史结果会按原状恢复。可随时清空全部历史。

## 凭据管理

API Key、Session ID 等敏感信息保存在本地配置中，不会上传到任何第三方。

## 由 AI 创作管家驱动

内置「创作管家」AI Agent，可以用自然语言指挥界面完成创作，例如：

- "画一张赛博朋克风格的城市夜景"
- "用即梦生成 1:1 的猫咪头像"
- "我之前生成过哪些图？"
- "把最近一张图改成水彩风格"
- "把第一张图变成视频"

管家会按需查询可用工具、读取历史、切换模式、填写表单并触发生成。

## 常见问题

**生成按钮没反应？**
请检查是否选择了提供商与模型，以及必填字段是否填写完整。

**需要公网 URL 的模式报错？**
请先在插件配置中填写 `workflow.aliyun-oss` 或 `workflow.tencent-cos` 的访问密钥。

**看不到历史结果？**
结果保存在本地配置文件中，删除浏览器数据或更换设备会丢失历史。
