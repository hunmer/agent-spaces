# 电子书转播客 (podcast_generator)

> 把 EPUB 电子书改编成双人播客对话脚本。AI 主持人 + 嘉宾陪你「聊」完一本书。

## 这是什么

电子书转播客让你上传 EPUB 格式的电子书，自动解析章节目录，选中任意章节后，AI 会把章节正文改编成一段生动有趣的双人播客对话（主持人 + 嘉宾），用对话气泡的形式呈现。

整个应用采用三栏布局：左侧章节目录、中间章节正文、右侧播客脚本。

## 主要能力

| 能力 | 说明 |
| --- | --- |
| EPUB 解析 | 自动解析电子书的元信息（书名、作者等）和完整章节目录 |
| 章节阅读 | 在中间栏阅读选中章节的纯文本正文 |
| AI 播客生成 | 选中章节后一键生成双人播客对话脚本 |
| 模型选择 | 顶部下拉框可选择不同的 AI 预设 |
| 历史恢复 | 上传的电子书、选中的章节、生成的脚本都会自动恢复 |

## 使用流程

1. 点击顶部「上传」按钮，选择本地 EPUB 文件
2. 应用自动解析书名、作者与章节目录
3. 在左栏选择想要朗读的章节
4. 中间栏展示该章节的纯文本正文
5. （可选）在顶部下拉框中选择 AI 模型预设
6. 点击中栏底部的「生成本章播客」按钮
7. 右栏展示生成的双人对话气泡
8. 关闭或刷新页面后，再次打开会自动恢复到上次的进度

## 对话脚本格式

AI 生成的播客脚本按行解析为对话气泡：

```
主持人：今天我们来聊聊这本书的第 3 章。
嘉宾：这一章其实讲的是……
主持人：……
```

- 角色在「：」左侧，内容在右侧
- 未知角色会自动归为「旁白」

## 适用场景

- 通勤路上用「听」的方式快速了解一本书
- 把专业内容转成轻松的对话便于学习
- 为视障人群生成可朗读的对话脚本
- 把长章节浓缩成有节奏的播客

## 状态恢复

应用会记住以下信息，关闭后再次打开会恢复：

- 上传的 EPUB 文件路径
- 书籍元信息（书名、作者等）
- 当前选中的章节
- 选中的 AI 模型预设
- 已生成的播客脚本

如果文件被移动或删除，会提示重新上传。

## 常见问题

**章节列表显示「第 N 章」而不是真实标题？**
部分 EPUB 的目录结构不规范，应用会按阅读顺序（spine）展示，无法匹配标题时回退到「第 N 章」。

**正文显示为空白？**
极少数 EPUB 含特殊排版，可能解析失败。可尝试重新上传或换一本书。

**生成按钮是灰色的？**
请先在顶部选择 AI 模型预设，模型选择后才能生成。

**生成时间较长？**
播客生成会创建一个完整的 AI 任务，开销大于普通聊天，请耐心等待。

**正文过长会被截断？**
单次生成时正文超过 12000 字符会被截断，提示词会注明已截断。超长章节可考虑分段生成。
