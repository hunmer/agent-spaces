# 文本连线支持变量级替换

## 目标

- 文本节点连接新节点时，目标属性下展示该字段现有文本中的 `{变量}`。
- 选择变量后仅替换该变量占位符；不选变量时保留整字段替换语义。
- 编辑态继续保存纯文本，变量仅做高亮展示。

## 阶段

1. [complete] 定位连接弹窗、文本输入派生和提示词编辑器实现。
2. [complete] 确定兼容旧边数据的最小数据结构与替换规则。
3. [complete] 实现弹窗交互和文本派生逻辑。
4. [complete] 添加回归测试并完成语法检查。

## 约束

- 保留工作区现有未提交修改。
