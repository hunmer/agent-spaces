# dom-inspector-hook

开发工具 NPM 包。通过 code-inspector-plugin 捕获页面元素源码信息（文件路径、行号、列名），POST 到自定义 URL。用于配合 Web 前端的 react-dev-inspector 实现点击元素跳转到源码。

## 约定

- peerDependency: `code-inspector-plugin >= 0.7.0`
- 构建工具: tsup
- MIT 开源协议
