# AI 音乐 (ai_music / SonicAI)

> 沉浸式 AI 音乐播放器，支持用自然语言描述创作独一无二的声音，并提供完整的播放、收藏、列表管理能力。

## 这是什么

AI 音乐是一个面向创作者的 AI 音乐播放器。你可以用一句「温暖的钢琴民谣、关于童年」就能生成一首完整的歌，也可以从内置曲库中点播喜欢的音乐，配合动态渐变背景与波形可视化，享受沉浸式聆听体验。

## 主要能力

| 能力 | 说明 |
| --- | --- |
| AI 创作 | 用文字描述风格、主题、情绪，一键生成完整歌曲 |
| 歌词生成 | 让 AI 帮你写歌词，再配合曲风生成带词的歌曲 |
| 纯音乐 | 切换「纯音乐」开关生成无人声的器乐曲 |
| 歌曲点播 | 从历史播放列表中点播任意一首 |
| 红心收藏 | 收藏喜欢的歌曲，方便快速找回 |
| 多种播放模式 | 顺序播放 / 单曲循环 / 随机播放 |
| 波形跳转 | 点击波形任意位置即可跳转到对应播放进度 |
| 音量调节 | 顶部右侧音量按钮，可调音量或一键静音 |
| 启动恢复 | 开启后再次打开会自动续播上次听的歌曲 |

## 使用流程

1. 点击页面底部居中的「创作」按钮
2. 在弹窗中描述想要的音乐风格（例如：「慵懒的爵士、女声、关于城市夜晚」）
3. （可选）填写歌词，或点击歌词框旁的 AI 图标让 AI 帮你生成歌词
4. 选择模型与是否纯音乐
5. 点击「生成」
6. 页面右上角会显示「正在生成中」，生成完成后会自动开始播放

## 播放器操作

- **播放 / 暂停**：中央大圆形按钮
- **上一首 / 下一首**：左右两侧的箭头按钮
- **跳转进度**：点击波形任意位置
- **音量**：右侧音量图标（点图标可静音，弹窗可拖动调节）
- **播放模式**：左侧模式按钮循环切换 `顺序播放 → 单曲循环 → 随机播放`
- **红心收藏**：封面悬浮的红心图标可切换当前歌曲收藏；列表中的歌曲右侧也有红心
- **下载**：封面悬浮的下载图标可下载当前歌曲
- **播放列表**：下一首按钮右侧的列表图标，点击展开播放列表（支持翻页、点击播放）

## 收藏与列表

- 所有生成过的歌曲都自动保存到本地播放列表
- 收藏的歌曲在播放列表中以红心标识
- 在左上角齿轮 → 设置 → 「导出数据」可下载整个曲库为 JSON 文件
- 在设置中可一键清空歌曲列表（带二次确认）

## 启动恢复

默认开启「启动时恢复播放」。每次播放会自动记住上次在听的歌曲，下次打开应用时会自动续播。

如需关闭，进入设置 → 「启动时恢复播放」开关。

## 由音乐管家驱动

内置「音乐管家」AI Agent，可以用自然语言完成播放操作，例如：

- 「播放一首歌」
- 「下一首」
- 「上一首」
- 「暂停播放」
- 「有什么好听的音乐？」
- 「帮我写一首关于夏天的歌」
- 「写一段民谣歌词」

管家会自动查询工具列表与曲库，调用合适的播放或生成 API。

## 数据存储

- 播放历史与设置保存在浏览器本地（localStorage），跨设备不会同步
- 导出的曲库 JSON 可作为备份，必要时重新导入

## 常见问题

**生成一直没反应？**
请检查顶部是否有「正在生成中」提示。如长时间无响应，请重试或联系管理员检查 `workflow.minimax` 插件配置。

**列表里的歌曲打不开？**
如果更换了设备或清空浏览器数据，已播放的本地列表会丢失。生成歌曲时建议及时导出备份。

**收藏的歌曲不见了？**
收藏状态保存在本地，浏览器数据清理后会被清空。
