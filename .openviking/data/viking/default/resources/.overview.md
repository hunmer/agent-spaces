# resources

这是一个综合性的技术文档资源目录，主要包含工作流系统、插件开发、国际化等相关技术文档和指南。该目录汇集了多个子目录，涵盖工作流节点设计、插件开发规范、Chat系统架构、i18n实现等多个技术领域。内容面向需要开发或扩展工作流引擎、创建自定义插件、实现国际化功能的工程师和开发者，提供详细的技术指导、API文档和实现规范。核心关键词包括"工作流"、"插件开发"、"节点设计"、"国际化"、"Chat系统"等。

## 快速导航

- **想了解工作流节点开发** → `compound-workflow-nodes/` [组合节点与循环节点] → `builtin-workflow-node-registration/` [内置节点注册] → `workflow-node-state-breakpoint/` [节点状态与断点]
- **需要插件开发指南** → `plugin-guide/` [插件开发] → `plugin-local-testing/` [本地测试] → `client-plugin-runtime/` [客户端插件运行时]
- **关注工作流输出字段** → `workflow-output-field-types/` [输出字段类型]
- **需要Web编辑器实现参考** → `loop-loop-body-implementation/` [循环节点实现]
- **想了解Chat系统** → `chat-capabilities/` [Chat能力说明]
- **需要国际化支持** → `i18n-guide/` [国际化指南]
- **关注交互节点实现** → `interactive-nodes/` [交互节点]

### workflow-node-state-breakpoint/
本目录包含一份关于工作流节点状态与断点能力的参考文档，核心围绕工作流节点执行控制功能展开，详细说明节点状态（normal/disabled/skipped）和断点（start/end）的数据模型、运行时行为及前端实现。文档涵盖状态对节点执行策略的影响、断点触发运行时暂停的机制，以及状态和断点通过右键菜单或事件更新的方式，同时涉及执行暂停时的数据流和前端控制条设计。适合具备工作流系统基础知识的开发人员，用于实现或理解工作流节点的执行控制逻辑。
