## 详细描述
### workflow-output-field-types.md
本文档是关于工作流节点输出字段类型的参考指南，详细说明了不同输出类型的定义、行为及在插件中的使用方法。主要涵盖内容：输出字段类型分类（标量、媒体、数组），各类型的值格式和说明；媒体类型（image、audio、video）在编辑阶段和执行后的预览行为，包括递归提取嵌套结构中的媒体资源；插件中如何通过outputs数组定义字段类型，以及run函数返回值的对应处理；技术实现细节如TypeScript类型定义、前端组件和辅助函数。关键信息：输出字段通过type声明类型，决定编辑器展示和执行渲染；媒体类型支持预览和递归提取；插件需正确配置outputs和返回值；相关代码位于shared和web包中。目标受众为工作流系统开发者，需了解输出字段配置和媒体处理机制，前提是熟悉工作流架构和TypeScript。
