## 详细描述

### command-palette.mdx.md command-palette.mdx.md

本文档是Agent Spaces的Command Palette参考指南，主要介绍其功能、实现细节及自定义方法。文档涵盖功能概览（通过Ctrl+K唤起，支持工作空间、频道等搜索及自定义命令）、搜索提供者（6个内置provider，对应不同数据类型，通过prefix/aliases匹配输入）、自定义命令（通过useCommandPalette store注册，支持分组展示）及技术实现（基于cmdk组件库、Zustand store管理状态、shadcn/ui渲染）。目标受众为开发者，需了解Command Palette的使用与扩展，前提知识包括React、Zustand及shadcn/ui基础。
