## Detailed Description
### chat-capabilities.md chat-capabilities.md  
该文档是关于Agent Spaces中独立AI对话系统Chat的能力说明，属于参考文档，面向需要了解系统架构和功能的开发者或用户。文档主要涵盖Chat系统的概述、架构、核心概念、当前能力、API端点、存储结构和前端组件。核心概念包括全局ChatAgent、ChatWorkspace和ChatSession，支持多工作空间管理、SSE流式对话、消息重新生成及内置工具调用。关键功能有独立Agent配置、技能与MCP支持、输出风格模板和工作目录管理。API端点详细说明了工作空间、会话、消息和Agent的操作接口。存储结构采用分层目录管理Agent配置和会话数据。文档最后对比了Chat页面与频道聊天的区别，强调其一对一AI对话场景的独立性。
