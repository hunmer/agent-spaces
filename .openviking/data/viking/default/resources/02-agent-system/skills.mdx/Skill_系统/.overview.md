## 详细描述
### Skill_系统_7more_b304b9c6.md Skill_系统_7more_b304b9c6.md
这份文档是Agent Spaces中Skill系统的参考指南，核心内容如下：  
- **Skill定义与结构**：Skill通过Markdown提示词（含YAML前言）封装Agent能力，核心字段为`name`和`description`，目录结构需遵循特定规范。  
- **内置库与导入**：内置Skill库按功能分类（如`superpowers`、`tdd`等），支持从Store、批量导入、单文件、Git仓库等多种方式导入。  
- **Agent绑定机制**：Skill与Agent为多对多关系，通过Agent配置中的`skills`数组实现绑定，包含同步检查与更新机制。  
- **自定义管理**：涵盖Skill的创建、编辑、收藏、分组和删除操作，以及全局和Agent私有副本的数据布局。  
关键信息包括YAML前言结构、内置库分类、导入API、绑定方式、同步机制及文件管理接口，目标读者为需使用或扩展Skill系统的开发者。

### REST_API_汇总_2more_e9cf203e.md REST_API_汇总_2more_e9cf203e.md
该文档是Skill系统的REST API参考，主要内容如下：  
- **API端点列表**：以表格形式展示GET、PUT、DELETE、POST等方法的路径及用途，涵盖技能列出（`/api/skills`）、更新（`/api/skills/{id}`）、删除（`/api/skills/{id}`）、文件操作（`/api/skills/files`）、导入（`/api/skills/import-git`）和同步（`/api/skills/sync`）等功能。  
- **鉴权与事件机制**：所有接口受全局Bearer Token鉴权保护，Skill的增删改不通过WebSocket广播，前端需通过SDK返回值或重新拉取API刷新列表。  
关键信息包括各端点具体操作及鉴权要求，适用于需与Skill系统交互的开发者，需具备REST API基础知识和身份验证概念。
