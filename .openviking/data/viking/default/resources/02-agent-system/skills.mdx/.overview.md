# skills.mdx

本目录是Agent Spaces平台中Skill系统的文档集合，核心内容集中在子目录`Skill_系统/`中。该系统通过Markdown提示词（含YAML前言）封装Agent能力，支持多对多绑定、同步更新和文件管理，是Agent Spaces的核心功能模块之一。文档涵盖Skill的定义、结构、内置库、导入方式、与Agent的绑定机制、自定义创建方法及对应的REST API参考，适合Agent Spaces的开发者或用户了解如何使用及扩展Skill功能，快速上手或深入定制Agent能力。
