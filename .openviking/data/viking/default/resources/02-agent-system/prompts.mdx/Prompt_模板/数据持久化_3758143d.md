## 数据持久化

Prompt 模板存储在工作空间数据目录：

- **目录**：`~/.agent-spaces-data/prompt-templates/`
- **元数据**：`meta.json`，结构为 `{ templates: PromptTemplate[] }`
- **单条记录字段**：`id`（形如 `prompt-<timestamp>-<rand>`）、`name`、`content`、`storeId?`（来自 Store 导入时标记来源）、`createdAt`、`updatedAt`

每次增删改都会整体重写 `meta.json`。模板内容直接内联在元数据中（不像 Agent 模板拆分为独立 Markdown 文件），便于值匹配反查绑定关系。
