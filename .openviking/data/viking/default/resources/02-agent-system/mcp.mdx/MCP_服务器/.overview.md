这是一份关于MCP相关REST API的文档，主要介绍其路由、运行时使用方式及与Skills的区别。文档分为三个主要部分：首先详细列出`/api/mcps`下的REST路由，包括GET（列出所有MCP服务器）、POST（导入配置）、PUT（更新配置）、POST（收藏切换）和DELETE（删除）等方法的路径与功能；其次说明不同运行时（如Claude Code、Open Agent SDK、LangChain等）如何处理MCP服务器，强调通过归一化函数将MCP工具集成到Agent工具集；最后对比MCP与Skills的区别，指出Skills是Markdown形态的提示资产，而MCP提供可调用的真实工具函数，两者可共存。文档面向需要集成或管理MCP的开发者，需具备REST API和Agent运行时基础知识。
