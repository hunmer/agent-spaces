# interactive-nodes

This directory contains documentation for implementing interactive nodes in workflow systems, focusing on the mechanism where nodes pause during execution to await user confirmation or input. The tutorial covers the WebSocket-based backend/frontend interaction flow, existing examples like table_display, and provides a comprehensive 7-step process for developers to create new interactive nodes. It addresses key concepts including interaction types, schema definition, and custom view components integration. This resource is specifically designed for developers working on workflow automation systems who need to implement user-interactive components within their workflow architecture.

## Detailed Description

### interactive-nodes.md interactive-nodes.md

This comprehensive tutorial guide explains the concept and implementation of interactive nodes within workflow systems. The document details the workflow mechanism where nodes temporarily pause execution to await user confirmation or input, creating a dynamic interaction point in automated processes. It covers the WebSocket-based communication flow between backend and frontend components, explaining how nodes can interrupt normal workflow execution to solicit user interaction.

The guide includes practical examples, such as the table_display node, demonstrating real-world applications of interactive functionality. A structured 7-step process is provided for developers to implement new interactive nodes, covering: defining interaction types, creating backend logic, establishing WebSocket communication, developing UI components, integrating with workflow schemas, testing implementations, and deploying the new nodes.

Key concepts explored include interaction type definitions, schema configuration for interactive nodes, and the development of custom view components that facilitate user interaction. The document assumes readers have familiarity with workflow architecture and basic frontend/backend integration principles, making it suitable for developers building or extending workflow automation systems that require human-in-the-loop decision points.
