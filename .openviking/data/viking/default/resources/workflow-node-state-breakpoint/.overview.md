# workflow-node-state-breakpoint

本目录包含一份关于工作流节点状态与断点能力的参考文档，核心围绕工作流节点执行控制功能展开，详细说明节点状态（normal/disabled/skipped）和断点（start/end）的数据模型、运行时行为及前端实现。文档涵盖状态对节点执行策略的影响、断点触发运行时暂停的机制，以及状态和断点通过右键菜单或事件更新的方式，同时涉及执行暂停时的数据流和前端控制条设计。适合具备工作流系统基础知识的开发人员，用于实现或理解工作流节点的执行控制逻辑。

## 详细描述
### workflow-node-state-breakpoint.md  
本文档是关于工作流节点状态与断点能力的参考文档，详细说明了节点状态和断点的数据模型、运行时行为及前端实现。文档主要涵盖数据模型定义、节点状态（normal/disabled/skipped）、断点（start/end）、执行时暂停机制及前端数据流。关键信息包括：节点状态和断点通过WorkflowNode顶层字段控制；状态影响节点执行策略，断点触发运行时暂停；状态和断点可通过右键菜单或事件更新；执行暂停有特定数据流和前端控制条。该文档面向需要实现或理解工作流节点执行控制功能的开发人员，要求具备工作流系统基础知识。
