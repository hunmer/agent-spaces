# output-styles.mdx

本目录包含关于输出风格管理功能的文档，主要介绍如何自定义Agent的输出格式模板，以控制回复的结构和样式。内容涵盖输出风格的核心概念（如Markdown格式模板）、系统内置的7种开发者风格（如carmack-mode、linus-mode等）、创建输出风格的步骤、将风格应用到Agent的方法、管理输出风格的途径、数据持久化机制（存储于工作空间.meta.json）及技术实现（运行时通过resolveOutputStyleContent()注入systemPrompt）。该文档面向需要自定义Agent输出格式的开发者或用户，需具备Markdown模板配置和Agent预设管理的基础知识。
