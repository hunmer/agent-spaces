## Detailed Description

### docker-deployment.mdx.md

This document serves as a complete tutorial and reference guide for deploying the Agent Spaces Server using Docker. It provides detailed instructions covering the entire deployment process from installation to configuration. The guide begins with quick start options using npm scripts (`pnpm build:docker` and `pnpm up`) for simplified deployment, then moves to comprehensive Docker installation instructions for Windows, macOS, and Linux environments.

The document explains the multi-stage Docker build process used for the server, which results in optimized container images. It covers building and exporting Docker images, as well as importing pre-built images for convenience. For running the server, it provides detailed `docker run` commands with explanations of all necessary parameters and options.

The guide includes a complete Docker Compose setup for orchestration, making it easy to deploy the server with all its dependencies. It explains data persistence through the `/root/.agent-spaces-data` directory and covers important configuration through environment variables including `PORT`, `HOST`, and various model API keys.

Key technical details covered include the server listening on port 3100, npm script utilities for deployment, and comprehensive environment variable configuration. The document assumes basic Docker knowledge but provides clear, step-by-step instructions suitable for developers looking to deploy the Agent Spaces Server in containerized environments.
