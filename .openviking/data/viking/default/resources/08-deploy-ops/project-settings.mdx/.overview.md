这是一个关于Agent Spaces项目设置功能的文档目录，主要介绍工作空间级配置和全局独立设置页面的管理功能。文档详细说明了Prompt配置、通知渠道、Agent预设、技能、MCP、LLM模型等各项设置的作用及访问方式，帮助用户和管理员系统配置工作空间参数。内容涵盖工作空间级的Prompt配置（影响Agent行为）、通知渠道设置，以及全局配置中的Agent预设管理、技能配置、MCP设置、LLM模型选择等，还包括语言切换和Git配置等实用功能。适用于Agent Spaces的用户或管理员，用于系统参数配置和管理。
