## 详细描述

### agent-sse-api.mdx.md agent-sse-api.mdx.md

这份文档是Agent SSE API的参考指南，主要介绍如何通过HTTP Server-Sent Events接口触发Agent执行，适用于外部集成、CI/CD管道和API测试场景。

文档涵盖的主要内容包括：接口地址（POST /api/agent-sse/run）、三种认证方式（Bearer Token、自定义Header或Body参数）、请求体参数（如agentId、message、systemPrompt等）、响应格式（SSE流事件类型包括session、status、output等）、使用示例（curl、Python、Node.js）以及不同运行时的流式行为差异。

关键信息包括：必须使用POST方法，支持实时流式输出（除open-agent-sdk外），客户端需设置足够超时，断开连接会自动停止执行。文档强调直接连接后端避免代理缓冲，并提供多种语言调用示例。

目标受众为需要集成Agent功能的开发者，需具备HTTP API和SSE基础知识，适用于构建自动化工具、CI/CD集成或API测试场景。
