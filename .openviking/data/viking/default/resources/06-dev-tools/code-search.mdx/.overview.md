## 详细描述

### code-search.mdx.md code-search.mdx.md

该文档主要介绍 Agent Spaces 的代码搜索功能，涵盖其能力、使用方法及 API 参考。主要内容包括搜索能力（代码内容搜索与文件名搜索）、.gitignore 支持、使用步骤及 API 端点。代码搜索基于 ripgrep（优先）和 Node.js（回退）实现文本级搜索，支持正则表达式、文件模式过滤、大小写敏感设置及结果数量限制，同时解析 .gitignore 并内置忽略目录和文件类型。使用时可通过编辑器图标或快捷键打开面板，输入关键词并可选配置选项。API 提供 `/api/workspaces/:id/search/code` 和 `/api/workspaces/:id/search/files` 端点，参数包括查询关键词、正则模式、大小写敏感等，返回包含文件路径、行号及匹配文本的结果。文档类型为 API 参考指南，目标受众为需要使用或集成 Agent Spaces 代码搜索功能的开发者，需了解基本代码编辑和 REST API 知识。
