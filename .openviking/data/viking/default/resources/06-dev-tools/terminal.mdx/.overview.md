# terminal.mdx

这个目录包含关于Agent Spaces终端功能的文档，主要介绍基于xterm.js和node-pty实现的终端集成功能。文档详细说明了终端的核心特性，包括真实PTY支持、多实例运行、WebSocket通信等，以及如何在工作空间内使用终端执行各类命令。内容还涵盖了快捷命令系统、虚拟键盘和常用快捷键（如Ctrl+C中断命令）等实用功能。该文档适合使用Agent Spaces的开发者或用户，帮助他们了解终端功能的使用方法和最佳实践。
