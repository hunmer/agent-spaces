### Persistence_And_E_4more_713ec74f.md Persistence_And_E_4more_713ec74f.md  
本文档是关于工作流系统持久化和外部边界的参考文档，详细说明了工作流的存储结构、触发器生命周期以及相关设计考虑。文档主要涵盖三个部分：首先是工作流存储结构，描述了每个工作流使用独立目录存储，包含工作流定义、版本快照、执行历史、插件配置等文件，并支持旧格式迁移；其次是外部边界，列举了WebSocket、HTTP、cron调度、文件系统等多种与外部系统交互的方式；最后是触发器注册生命周期，解释了WorkflowTriggerService如何管理cron和hook触发器的注册、重载和移除。关键信息包括：工作流存储的目录模型和各文件用途，触发器注册的核心逻辑，以及系统存在的开放问题和风险，如缺少统一的执行事件作用域模型、恢复机制不完整、触发器注册状态纯内存等。本文档面向需要理解工作流系统底层实现和设计的开发人员，特别是后端工程师，需要具备对工作流、存储和触发器等概念的基本了解。
