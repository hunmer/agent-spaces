# Adding_A_Workflow_Node_Guide

本指南是关于在工作流系统中添加新节点的实施指南集合，专为开发者设计。它详细阐述了实现工作流节点的多种路径（如内建节点、服务端插件、客户端插件），并提供了从节点定义、前端注册、国际化（i18n）到服务端执行、输出契约定义的12步核心流程。指南强调各环节的完整性，旨在帮助开发者避免“节点创建成功但无法执行”等常见问题，是理解代码结构与实现细节的宝贵资源，尤其适合需要实现内建或插件节点的开发者。

## 快速导航

- 你想了解添加工作流节点的完整流程 → `Scope/ [1]`
- 你想选择合适的实现路径（内建/插件） → `Scope/ [1]`
- 你想了解12步核心流程的细节 → `Scope/ [1]`
- 你想处理复合节点 → `Scope/ [1]`

## 详细描述

### Scope/
Scope目录是关于workflow node（工作流节点）新增的实施指南集合，聚焦为开发者提供从代码入口到最小可运行链路的完整指引。内容涵盖实现路径选择（内建/服务端插件/客户端插件）、12步核心流程（如节点定义、前端注册、i18n添加、服务端执行、输出契约等）及复合节点处理，强调各环节完整性以避免“能创建不能执行”等问题。适合需实现内建或插件节点的开发者，帮助其理解代码结构与实现细节，提供步骤化指引与文件改动建议。
