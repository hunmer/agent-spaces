## 详细描述

### workflow.mdx.md

本文件是关于 Agent Spaces 平台中 Workflow 编辑器的指南，主要介绍其作为核心编排机制的功能和用法。

文档首先定义了 Workflow 是一个有向无环图（DAG）模板，用于定义节点间的执行顺序和依赖关系。接着详细说明了创建 Workflow 模板的步骤，包括进入页面、创建新模板、添加不同类型的节点（如 Agent 节点、流程控制节点、AI 节点、展示渲染节点、交互节点、字符串与工具节点、SQL 数据库节点）以及通过连线定义依赖关系。

关键信息包括：
- Workflow 节点类型丰富，涵盖 Agent 执行、流程控制、AI 调用、数据展示、用户交互、数据处理和数据库操作。
- 保存时会进行 DAG 校验，确保流程有效。
- Workflow 与 Issue 关联，可在创建 Issue 时选择模板，系统会按依赖关系调度执行 Agent 节点作为 Task。
- 运行前会进行校验，确保绑定的 Agent 存在、启用且属于当前 Issue 频道成员。
- 提供迷你 DAG 预览和列表管理功能，并通过 WebSocket 实现实时状态更新。

本指南面向需要使用 Agent Spaces 平台进行任务自动化编排的用户，假设读者了解基本的 DAG 概念和平台操作。
