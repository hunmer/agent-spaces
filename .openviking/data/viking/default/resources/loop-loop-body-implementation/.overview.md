# loop-loop-body-implementation

本目录包含Web编辑器中`loop`/`loop_body`关键实现的技术参考文档，聚焦节点结构、布局同步、渲染层级、节点操作规则及删除约束等核心逻辑。文档旨在为需维护或迁移该功能的开发者提供技术依据，涵盖`loop`作为根节点、`loop_body`作为自动生成scope边界的结构设计，内置`start`/`end`边界节点的生成与边关系，通过内部子节点反推Scope大小的布局机制，低zIndex避免`loop_body`覆盖内部节点的渲染策略，以及scope归属、边拆分、级联删除等操作规则。适合具备工作流节点、ReactFlow基础知识的开发者阅读。

## Detailed Description
### loop-loop-body-implementation.md
本文档是关于Web编辑器中`loop`/`loop_body`关键实现的技术参考，记录其结构、布局、渲染及删除约束，供维护迁移使用。主要涵盖节点结构（`loop`为根节点，`loop_body`为自动生成的scope边界）、内置边界节点（`start`/`end`的生成与边关系）、Scope布局同步（通过内部子节点反推大小）、渲染层级（`loop_body`低zIndex避免覆盖内部节点）、节点插入与连线规则（scope归属及边拆分逻辑）、删除约束（`loop_body`及内部生成节点禁止单独删除，级联删除规则）。目标受众为需理解或维护该逻辑的开发者，需具备工作流节点、ReactFlow等基础知识。
