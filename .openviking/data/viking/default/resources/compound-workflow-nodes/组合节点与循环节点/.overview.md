## Detailed Description

### 如何注册类似节点.md 如何注册类似节点.md  
本教程指导开发者注册两类“类似节点”：组合结构节点和需控制执行语义的节点。第一类通过声明 `compound` 实现，步骤包括注册根节点（含 `compound` 配置）、隐藏子节点、同步到 Electron 内建节点及可选 UI 接入；第二类需扩展执行器，修改 `backend/workflow/execution-manager.ts` 和 `src/lib/workflow/engine.ts`，在 `dispatchNode` 中为根节点增加分支，通过隐藏子节点调度内部节点。受众需具备节点注册、执行器逻辑及 TypeScript 配置知识。

### 组合节点与循环节点_7more_92e9f223.md 组合节点与循环节点_7more_92e9f223.md  
技术指南详细说明组合节点模型及循环节点实现。组合节点解决单节点无法表达的固定结构问题，核心数据模型通过 `rootId` 和 `parentId` 维护层级关系；循环节点包含可见根节点 `loop` 与隐藏子节点 `loop_body`，自动生成受保护连线。运行时语义涉及迭代次数、作用域执行及中间变量机制，编辑器约束包括自动创建、隐藏节点及禁止手动操作内部结构。需具备工作流系统基础知识，关注节点定义、执行逻辑和编辑器交互实现。

### 插件节点如何复用这套能力_4more_2299ea3b.md 插件节点如何复用这套能力_4more_2299ea3b.md  
指南说明插件节点如何复用组合节点能力，面向需实现复杂节点结构的开发者。文档介绍插件侧支持的类型声明（如 `manualCreate`、`compound`），通过最小示例展示组合节点实现，并指出当前限制：`compound` 主要复用编辑器层能力，强流程控制语义（如循环）仍需内建执行器配合。提供循环节点注册片段及文件索引，强调新增机制可复用，后续 `retry`、`parallel` 等节点应沿此路径扩展。
