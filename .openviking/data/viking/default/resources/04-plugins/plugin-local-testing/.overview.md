# plugin-local-testing

This directory contains documentation and resources for locally testing server plugins using a TypeScript runner. The guide focuses on validating plugin functionality during development by testing `actions.js` method return values without requiring the full application installation or launch. It provides a practical workflow for developers working on server plugins, emphasizing independence from web/Electron environments. The documentation covers testing scope, entry files, basic commands, parameters, custom test files, inline code execution, plugin configuration passing, and mocking host APIs. This resource is particularly valuable for TypeScript developers familiar with plugin structures who need to validate plugin functionality efficiently during development.

### plugin-local-testing.md plugin-local-testing.md

This document serves as a comprehensive tutorial guide explaining how to locally test server plugins using a TypeScript runner. The guide focuses specifically on testing `actions.js` method return values without the need to install or launch the complete application. The main sections cover the testing scope (server plugins), entry files, basic commands, parameters, custom test files, inline code execution, plugin configuration passing, and mocking host APIs. Key information includes using commands like `pnpm test:plugin:fetch`, parameters such as `--plugin`, `--test`, and `--mock-api`, and methods like `plugin.runAction()` for executing actions. The guide emphasizes the independence from web/Electron environments and provides practical examples for configuration and API mocking. This resource is intended for developers working on server plugins, assuming familiarity with TypeScript and plugin structures, and offers a practical workflow for validating plugin functionality during development.
