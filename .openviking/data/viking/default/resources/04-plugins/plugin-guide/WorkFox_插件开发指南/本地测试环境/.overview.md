### 本地测试环境_2more_031b0902.md 本地测试环境_2more_031b0902.md

- **多文件工具导出结构**：需遵循统一导出规范，拆分建议按能力分类（如工具入口、动作定义、核心逻辑分离），确保模块化可维护；  
- **复用方案**：通过`actions.js`统一定义动作，在`main.js`中注册，实现Workflow和Tool的复用，动作字段约定明确（如`name`、`description`、`params`等）；  
- **关键要点**：多文件工具的拆分逻辑、动作复用机制及字段规范，帮助开发者高效构建可扩展的插件测试环境。  

目标受众为需配置插件本地测试环境的开发者，需理解工具与Workflow的复用逻辑，避免重复开发。


### property_字段类型type_与_dataType.md property_字段类型type_与_dataType.md  
该文档是表单属性字段类型的配置参考，聚焦`type`（UI控件类型）与`dataType`（实际数据类型）的区别及使用规则：  
- **核心分工**：`type`仅影响UI渲染（如`text`控件显示输入框），`dataType`是数据类型的唯一来源（如`string`），即使控件类型看似能推断数据类型也必须显式设置；  
- **映射规则**：详细说明不同`type`（如`select`、`number`）对应的推荐`dataType`，确保Agent Tool JSON Schema生成、节点测试对话框解析及`run()`函数处理的数据正确性；  
- **扩展功能**：简要介绍插件节点的`customView`功能，支持React和HTML两种渲染模式，允许自定义节点视图。  

核心要点为`type`与`dataType`的明确分工、严格的数据类型映射及自定义视图支持，适合需要配置表单属性或开发插件节点的开发者参考。
