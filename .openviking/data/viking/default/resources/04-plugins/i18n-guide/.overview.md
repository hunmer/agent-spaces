## Detailed Description

### i18n-guide.md i18n-guide.md

This document is an i18n development guide for a project using next-intl, explaining how to implement internationalization through translation file structure, adding translations, and using them in components, with specific instructions for workflow nodes.  

Main sections cover translation file organization (namespaces stored in src/locales/), quick steps to add translations (adding keys to JSON files, using useTranslations in components), variable translations, and workflow node i18n (auto-translation for 'nodes.'-prefixed keys, adding node-specific translations, and category handling).  

Key takeaways: Translation files must have consistent structure across languages; use useTranslations('namespace') to load translations and t('key') to access values; use {varName} for variables; workflow nodes use 'nodes.' prefixed keys for auto-translation; follow naming conventions for namespaces (avoid overusing 'common').  

Intended audience: Developers working on the project who need to add or manage translations, requiring familiarity with React/Next.js and TypeScript.
