client-plugin-runtime 是一个专注于客户端插件运行机制的技术文档目录，主要面向Electron环境下的插件开发者。该目录内容围绕插件开发的两大核心主题展开：插件目录规范与执行机制。文档详细阐述了符合要求的插件目录结构（如info.json、actions.js等文件配置）、CommonJS加载规则、结果返回格式，以及客户端插件的执行模型（包括适用场景、内置插件、IPC通信等）。
