本目录包含关于 Agent Spaces 平台中 Workflow 编辑器的文档，主要介绍其作为核心编排机制的功能和用法。Workflow 是一个有向无环图（DAG）模板，用于定义节点间的执行顺序和依赖关系。

文档详细说明了创建 Workflow 模板的步骤，包括添加不同类型的节点（如 Agent 节点、流程控制节点、AI 节点等）以及通过连线定义依赖关系。内容涵盖 Workflow 的节点类型、执行顺序控制、依赖关系管理等功能特性。
