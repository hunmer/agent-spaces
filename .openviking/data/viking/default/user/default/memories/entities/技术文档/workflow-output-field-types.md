本目录包含一份关于工作流节点输出字段类型的参考指南文档。文档详细说明了不同输出类型的定义、行为及在插件中的使用方法，涵盖输出字段类型分类（标量、媒体、数组）、各类型的值格式与说明，媒体类型（image、audio、video）在编辑阶段和执行后的预览行为（包括递归提取嵌套结构中的媒体资源），插件中通过outputs数组定义字段类型及运行时行为。
