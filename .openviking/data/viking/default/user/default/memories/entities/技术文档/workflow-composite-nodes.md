Workflow_Composite_Nodes是workflow系统的核心技术文档模块，专注于composite node（复合节点）的设计与实现，重点涵盖loop（循环）、loop_body（循环体）和sub_workflow（子工作流）的技术细节。文档覆盖composite node的定义、创建流程、前端布局规则及服务端执行逻辑，包括复合模型、工具函数、节点工厂扩展、前端布局、执行模型等关键内容。
