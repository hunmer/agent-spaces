# ComfyUI_SDK

The ComfyUI_SDK is a TypeScript library for interacting with the ComfyUI API, focusing on workflow construction, execution orchestration, and multi-instance management. It provides a fully typed API with Workflow and PromptBuilder tools, WebSocket event handling, multi-instance pooling with health checks, and modular extensions. The SDK is designed for developers integrating ComfyUI into applications, assuming familiarity with TypeScript and Node.js (v22+). It offers both reference and tutorial-style guidance for building and managing ComfyUI workflows programmatically.
